# 定制能力生命周期与历史导航验收

日期：2026-09-28。环境：macOS、Node.js 24.15.0、Chrome/Playwright。变更：`streamline-customization-lifecycle-and-history`。

## 实现范围

- 我的定制、模型、管理三级主入口；管理子入口保留资源、权限、候选、能力包、MCP、工作流和面板操作。控件使用当前主题的语义颜色，头部和卡片布局收紧。
- 校验反馈绑定资源与版本，成功提示可关闭，加载历史默认折叠；生命周期证据独立记录静态、模拟、预览、加载及宿主阶段。过期版本或宿主证据不为当前版本背书。
- 来源区分受控创建、关联更新与未知来源；关联会话失效不删除能力。已激活候选不重复展示，内部桥接权限不作为用户能力列卡片。
- `customization_status` 查询当前宿主与固定运行快照的差异，并返回版本绑定的交付卡。新增权限确认校验内容与授权版本，加载失败保留旧活动版本。主题加载后仍需预览和应用。
- 构建产物生成 `build-identity.json`。SDK 查询报告实际构建、契约、运行入口和 Node 路径；源码宿主明确提示构建要求，不借 PATH 推测安装身份。
- 候选二进制清单保留原字节与摘要，兼容旧文本候选；激活、加载、导出和回滚均覆盖字体/图片，篡改与格式不符会失败。
- 统一颜色字面值解析，接受短长十六进制、RGB/HSL 与透明度，移除对比度阻断和自动改色。
- 历史窗口最多 180 行，前后分页、返回最新、实时水位分离；迟到响应和错误不能覆盖后发导航，历史浏览有新消息提示，返回最新显式滚动。

## 验收方式

单元覆盖旧候选摘要、原始字节、导出解包、回滚/篡改、颜色语法、来源重启保留、版本证据失效、只读查询、新权限可见与已激活候选去重。

浏览器覆盖默认导航、反馈跨分类隔离、权限确认/取消、主题预览取消、失效交付卡只读打开、模型草稿与失败恢复、键盘、360px、200% 等效视口、reduced-motion；450 行历史加载到最早再返回最新、迟到分页、失败重试、切会话和持续 SSE 更新。

安装包使用 `node scripts/pack-smoke.mjs` 的干净本地/全局安装，验证公开 SDK、文档、命令、面板、Provider、工作流、MCP 和导入导出。新增夹具为同一面板添加完整主题及真实 WOFF/PNG，检查权限扩展拒绝、版本冲突、应用、原始字节、导出及回滚。

`node scripts/pack-theme-browser.mjs <安装目录>` 只从安装包加载运行时，在 Chrome 中核验字体加载、PNG 背景嵌入及实际主题颜色；截图保存于 `output/playwright/installed-customization-theme.png`。未复制私人会话作为夹具。

## 边界

- 未知外部编辑者不会被推断为当前会话作者；权限仍需用户显式确认。
- 浏览器确认样式已应用并不等于用户已认可审美效果；模拟、预览和宿主证据分别展示。
- 64 轮测试保留完整轮数断言，单项预算由 15 秒调为 60 秒，避免持久化与并行集成测试争用磁盘导致假超时。
- 构建仍有现有主包大于 500 kB 的 Vite 提示；本变更未做无关的打包拆分。
- 本轮不提交、不推送、不归档。
