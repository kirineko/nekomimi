# 聊天导航与按需加载验收

变更：`refine-chat-navigation-and-loading`。日期：2026-09-28。

## 基线

命令：`npm run build`，然后 `node scripts/web-loading-metrics.mjs`。生产产物、Chrome、新建冷缓存上下文、空聊天工作区，记录页面启动后 500ms 内全部 JS 请求；字节数按 minified 文件长度，gzip 统一使用 Node gzipSync（与 Vite 压缩级别可能不同）。

变更前主分块 `index-C2N6fbaG.js` 为 510752 字节、gzip 154566 字节，首屏仅此 JS 分块，构建出现 500 kB 告警。定制、文件、变更、检查器与导出由 App 静态导入；Customization 内的常驻交互与 WorkspacePanel 内的文件上下文是需保持可用的共享依赖。

## 实现与回归范围

- 5 个专用分块（定制、文件、变更、检查器、导出）首次打开才请求；常驻扩展交互及文件定位上下文保留。失败重试使用构建清单中的同源分块地址与独立重试 URL，避开浏览器对失败 import 的缓存，不加载任意远程 URL。已关闭界面不会因迟到加载而重开。
- 唯一返回入口位于输入区上方，不覆盖底部“查看较新”；最新底部不留占位。历史窗口仍有界、双向可达，前后分页失败在原入口重试，迟到响应和错误按会话/请求隔离。
- 最新模式在消息与布局变高时保持底部；程序性滚动不触发历史模式。主动向上阅读后保持锚点，有新消息只更新同一返回入口，回到最新后继续跟随。
- 提交确认后恢复输入；用户主动转移焦点、切会话或页面失焦后不抢焦点。失败留草稿，繁忙时可以写下一条草稿且不会提前提交。
- 用户补充范围：resource_write 默认 project，显式 user 保留写入授权；SDK 返回真实宿主 home 和两级路径，管理卡片/交付状态标注范围，增加用户级筛选。旧资源不迁移；用户候选开发与用户级能力包交付分别说明。

## 验证方法与限制

浏览器覆盖动态模块延迟关闭、首次网络失败后成功重试、鼠标与 Enter 提交、IME 与补全、焦点转移、忙时草稿、450 行历史、连续新增消息与延迟布局。窄屏按 360 CSS px 验证，200% 放大使用等效减半 CSS 视口（360×450）；不以 CSS zoom 放大 100dvh 冒充浏览器缩放。

新资源测试使用两个临时工作区和一个临时 home，验证默认项目路径、用户授权拒绝、范围错误、摘要冲突、共享发现、项目覆盖及覆盖移除。没有写入真实用户定制目录。新增默认值有意改变旧 resource_write 无 scope 的写入目标，需要用户级的旧调用应显式补上 scope:user；已存在资源与授权保持原位置。

全量单元/集成测试：46 个文件、253 项通过。全量浏览器首轮 42 项通过，另两项分别修正了异步模型启动断言的等待和 CSS zoom 的错误模拟方式，再复验；最终结果见后文。
