## 产物管理

版本库保留代码、规格、文字验收结论和协议验证数据。测试和运行截图属于临时产物，统一输出到根目录 `test-results/` 或系统临时目录，不复制到文档目录、不纳入版本控制。图片协议测试使用的合成数据属于测试输入，保留在测试代码中。

验收报告中的测试数字对应当时的验证记录；最新归档验收见上方链接。

- [SDK 2 定制开发](../extension-docs/v2.md)：能力包、Provider、MCP 内容/OAuth、持久流程与隔离面板。
- [V2 实施与验证](customization-v2-validation.md)：阶段证据、未完成门槛及候选状态。
