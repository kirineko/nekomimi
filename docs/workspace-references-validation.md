# 工作区引用块验证（2026-09-30）

变更：`add-workspace-reference-chips`。任务输入支持正文和文件／目录引用块，序列化为 `@path` 或 `@"JSON 转义路径"`。目录尾部保留 `/`；引用不附加文件内容，模型按需调用现有工具，Journal 仍保存用户文本和实际工具证据。

## 实现与边界

- 工作区只读候选接口复用认证、来源和 realpath 校验；提供模糊搜索、目录分页、刷新和精确路径校验。默认候选 20 项、遍历上限 50,000 项，索引有效期 5 秒；无正文读取或 shell 建索引。
- 引用块使用受限 contenteditable，正文与引用片段模型保存选区和最多 100 次撤销状态。中文组合期间不重建编辑节点；内部剪贴板有版本和路径校验，外部 HTML 不进入编辑 DOM。
- 目录候选的 Enter／Tab 引用与 ArrowRight 下钻分开；ArrowLeft 返回父级。命令与引用弹层互斥，候选绑定查询／会话，取消或迟到结果不能替换当前输入。
- 提交继续使用原 prompt、commandId 与去重哈希。发送失败保留引用，重载、导出、回放、导入不依据路径重新读取磁盘；已删除文件不影响历史证据读取。
- 非目标：外部目录、上传、完整 gitignore 解释、自动全文附件和历史消息引用块迁移。引用不授予额外工具权限。

## 验证覆盖

`test/references.test.ts` 覆盖特殊路径编解码、原子编辑与撤销、光标触发、邮箱／代码排除、查询排名和上限、目录分页变化、隐藏／排除目录定向访问、取消与并发扫描、符号链接以及提交文本限制。

`test/reference-evidence.test.ts` 使用合成模型响应，验证首个请求只有路径、工具后续请求包含实际内容、选择后修改的文件以读取时内容为准、缺失和截断有明确结果；删除原文件后导出／导入／回放仍保留原证据，不重新调用模型。

`test/browser/references.spec.ts` 在真实 Chrome 验证多引用、目录下钻、特殊文件名剪贴板、跨块选择、边界删除、撤销、失败重试、取消选择、迟到搜索、API 认证、原生中文组合输入，以及大工作区搜索。扩展追加草稿保留已有引用块；原有命令、草稿和焦点用例将 textarea 的 value 断言迁移为编辑器 textContent 精确断言，保持换行和空格检查。

中文组合使用 Chrome CDP `Input.imeSetComposition` 和 `Input.insertText`，另有组合事件期间 Enter 防误提交回归。剪贴板使用浏览器 DataTransfer／ClipboardEvent 验证两种 MIME；不将其写成操作系统剪贴板端到端实测。窄屏、字号放大及缩小可用视口均为浏览器自动化；物理手机软键盘、系统输入法、系统缩放、Safari／Firefox 和 Windows 尚未实测。

## IME 评审修复与复查

两条 P2 评审问题均在修复前的真实 Chrome 构建中复现：在引用块前组合输入“新增中文”后点击删除，正文被连带删除；内部引用粘贴校验迟到时，正在组合的“中文”被编辑 DOM 重建覆盖。

删除按钮改为操作时从当前 DOM 映射序列化范围，避免保存组合输入前的位置；组合输入中不执行删除。compositionstart 取消待完成的内部剪贴板校验，校验循环、最终转换及错误分支检查取消状态，取消保留已有纯文本且不提示校验错误。

新增两项 Chrome CDP 原生组合输入回归，检查正文精确内容、删除后撤销／重做、迟到结果不覆盖组合文字、提交组合后连续撤销以及无额外模型调用。修复后引用、焦点、命令、扩展草稿浏览器回归 **21/21 通过**（36.8s）；相关单元测试 **8/8 通过**，类型检查、严格规格校验 **42/42** 和差异检查通过。报告：`output/playwright/references-ime-review.json`。本轮未重跑全部后端测试，前轮全量结果见上文。

复查范围：引用节点身份与当前位置映射、组合期间 DOM 重建入口、剪贴板请求取消及迟到成功／失败处理、撤销状态。两条原评审问题已关闭；该范围内未发现新的待修问题。物理输入法及其他浏览器覆盖限制仍沿用上文。
