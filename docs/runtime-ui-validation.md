# 统一平台 SDK 与运行时 UI 验收

变更：`unify-platform-sdk-and-runtime-ui`。日期：2026-09-28。当前实现及开发入口见 [SDK 文档](../extension-docs/README.md) 和 [运行时 UI](../extension-docs/runtime-ui.md)。

## 交付范围

统一 `ExtensionAPI` / `ExtensionFactory`、能力发现和候选脚手架；旧清单与带后缀类型保留兼容，协议版本仍独立校验。文档按开发任务组织，包含命令、工具、Provider、工作流、状态、包、Skills/Rules/MCP、主题、视图和验收步骤。

主题覆盖字体与回退、排版、语义配色、间距、圆角、阴影、气泡、背景素材、动效和密度。全局默认与项目覆盖使用配置修订检查；主题预览可取消，恢复入口由宿主提供。字体与图片随包交付并参与资源摘要，不访问第三方资源。示例字体只包含拉丁字符，中文使用系统字体回退；许可随示例发布。

视图覆盖会话头部、消息内容、工具结果、输入工具栏、侧栏和独立页面。桥接验证授权、实例、版本和会话范围；草稿不自动发送，命令复用去重、取消和 Journal 收据。主题更新不重新挂载面板，关闭实例释放端口及订阅。

`/moe 小猫咪` 新结果直接显示互动卡片，历史与离线导出显示可读内容。内部 envelope、哈希及原始数据保留在折叠证据中。刷新不自动运行历史插件，用户可显式打开；成功状态不重复展示 fallback，收起后可重开。

## 执行结果

- `npm run typecheck`：通过。
- 单元测试：最终稳定的全量 `npx vitest run --maxWorkers=2` 为 42 个文件、244/244 通过；此前已执行 `npm test` 的构建与全量测试，默认并发触发两处时序超时，限制并发后完整复验通过。字体桥接补充后相关单元测试 12/12 通过。
- `npm run test:browser`：36/36 通过。补齐面板首次字体同步后，定制能力与运行时 UI 浏览器测试 11/11 通过；最终按钮样式和工具栏展开/收起复验 2/2 通过。
- `npm run test:pack`：通过。本地 tarball 在隔离临时目录安装，无真实模型凭证；随后最后一处按钮禁用态选择器调整通过重新构建和浏览器复验。
- `npm run test:release`：7/7 通过，仅验证发布规则，未发布包。
- `openspec validate --all --strict`：32/32 通过；`git diff --check` 通过。

回归发现并修正了历史面板标题/完成标记被过度隐藏、主题下侧栏按钮间距被覆盖、200% 下顶栏恢复入口裁切、面板首次挂载未获得字体数据、通用按钮背景覆盖强调按钮等问题。旧面板主题测试改为操作新的按钮组。新增按钮断言最初在空草稿禁用态检查强调背景，已改在填写草稿后检查可发送状态；保留禁用态样式。

## 本地证据与限制

本地效果截图：`output/playwright/runtime-ui-sakura.png`。宿主集成记录：`output/playwright/runtime-ui-verification.json`，包含实际受测资源 ID/revision；这些运行产物按项目惯例忽略入库。截图已人工审阅，包含粉紫色主题、紧凑侧栏、直接互动内容和工具栏入口。

用户截图可证实原视图泄漏技术数据与重复 fallback；静态会话导出不能确定原浏览器缺少 iframe 的唯一原因。本次使用独立的等价 `/moe 小猫咪` 夹具在真实宿主验证加载、握手、草稿操作、关闭及重开，不将私人会话写入仓库，不宣称已经重现全部原环境故障。

环境为 macOS、Node.js 24.15.0、Playwright 驱动本机 Chrome。200% 检查使用 CSS zoom，不等于操作系统缩放或实际 Chrome 用户缩放；未实测 Safari、Firefox、真实移动设备、屏幕阅读器或其他操作系统。恢复默认会持久保存项目默认主题并关闭当前页面扩展视图；刷新后仍启用的视图可重新出现。主题选择与资源授权分别管理，历史摘要无法重建已缺失插件的全部视觉。
