# 0.2.1 发布记录

## 本次更新

- 整合定制平台、SDK 与按需开发资料，完善项目/用户级作用域、授权、验证和效果交付；主题支持字体、配色、间距、气泡和动效。
- 优化定制能力面板、紧凑会话导航、斜杠命令发现及输入区底栏；修复历史浏览、最新消息跟随和发送后焦点问题。
- 新增上下文占用明细、自动压缩与 `/compact` 手动整理；`nekomimi web` 启动后自动打开浏览器。
- 分离主对话、压缩和命名提示，按实际工具组装指导，补全工具参数契约、来源记录与 SDK 导航。
- 改善响应中断处理与顶部操作，避免历史面板回放自动执行副作用，修复扩展重载恢复和生命周期证据。

## 平台范围与限制

本版发布门禁仅覆盖 Linux/macOS × Node.js 22.19.0/24.15.0。Windows 检查暂时移出，待 macOS/Linux 稳定后统一优化和恢复原生验证；不宣称 Windows 通过本版验收。

最低 Node.js 为 22.19.0。提示词真实模型质量评测尚未运行，不宣称完成率或缓存命中提升；完整工具契约会增加部分场景输入大小，详见 [验收记录](../validation/prompt-contracts/README.md)。
