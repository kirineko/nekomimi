# 0.2.1 发布记录

## 本次更新

- 整合定制平台、SDK 与按需开发资料，完善项目/用户级作用域、授权、验证和效果交付；主题支持字体、配色、间距、气泡和动效。
- 优化定制能力面板、紧凑会话导航、斜杠命令发现及输入区底栏；修复历史浏览、最新消息跟随和发送后焦点问题。
- 新增上下文占用明细、自动压缩与 `/compact` 手动整理；`nekomimi web` 启动后自动打开浏览器。
- 分离主对话、压缩和命名提示，按实际工具组装指导，补全工具参数契约、来源记录与 SDK 导航。
- 改善响应中断处理与顶部操作，避免历史面板回放自动执行副作用，修复扩展重载恢复和生命周期证据。

## 平台范围与限制

本版发布门禁仅覆盖 Linux/macOS × Node.js 22.19.0/24.15.0。Windows 检查暂时移出，待 macOS/Linux 稳定后统一优化和恢复原生验证；不宣称 Windows 通过本版验收。

最低 Node.js 为 22.19.0。提示词真实模型质量评测尚未运行，不宣称完成率或缓存命中提升；完整工具契约会增加部分场景输入大小，详见 [验收记录](../validation/prompt-contracts/README.md)。

## 发布验证

准备阶段：目标版本 0.2.1 经官方 npm registry 查询尚不存在。正式发布仅在本地验收与标签四组 CI 全部通过后执行；结果待实际完成后补充。

本地 macOS 验收（2026-09-28）：
- Node 24.15.0 类型检查、7 项发布检查通过。
- 完整单元测试 52 个文件、314 项通过（两个 worker）。
- 全部浏览器测试 45/45 通过。
- Node 22.19.0、engine-strict 安装包验收通过：全局 CLI/Web、工作区隔离、导出导入、SDK、能力包、Provider、工作流、面板、MCP、主题资源及候选激活/回退。
- OpenSpec 主规格同步及 Windows 检查延期变更归档完成；归档后 41 项严格校验和 git diff 检查通过。

远端标签 CI、npm 上传及 registry 核验尚待执行，不以本地结果代替跨平台发布门禁。

首轮标签 CI 中 macOS/Node 24 浏览器场景在切换消息 renderer 后过早点击另一 iframe，trace 未出现 view.open 请求。补充实际内容与状态订阅就绪检查，以及页面打开请求成功断言；未放宽超时、添加重试或改变产品执行逻辑。修正后重新验证标签门禁。

Linux 两组首轮 CI 也在筛选面板内容后的确认按钮处失败，trace 未出现 workflow.answer 请求。验证发现 iframe DOM、内部渲染、宿主高度同步分属不同阶段，且离屏 iframe 的尺寸通知可能被节流。测试统一先滚入视口，再检查内容与宿主高度同步、等待宿主布局观察器处理，随后进行真实鼠标点击并核对服务端请求。未改动产品逻辑、放宽超时或加入自动重试；2026-09-29 两项场景连续五轮共 10/10 通过，类型检查通过。首轮及中间验证失败保留为竞态诊断证据。
