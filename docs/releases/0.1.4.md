# Nekomimi 0.1.4

## 新增与改进

- 回答中的 Markdown 代码块、历史文件 diff 和离线 HTML 支持语法高亮，覆盖 JavaScript、TypeScript、TSX、Python、JSON、Shell 和 diff。
- 高亮保留历史证据、行号、增删标识和复制行为；未知语言、失败及超预算输入回退纯文本，流式输出与会话切换保持响应。
- `web_fetch` 支持显式覆盖、环境代理和 macOS/Windows 已启用的 HTTP(S) 系统静态代理，支持 NO_PROXY；代理连接失败不自动回退直连。
- 统一浏览器式请求头，明确识别网站验证页，普通 HTTP 403 保留原始失败分类。

## 正确性与边界

- 修复代理凭证在 HTML 转 Markdown 时因转义遗漏脱敏的问题，覆盖实体解码及解析分块。
- 文本脱敏保留 Journal 协议字段和 artifact 引用；原始 Content-Type 独立用于字符解码，避免短凭证与 MIME/charset 重合时破坏抓取。
- 代理负责远端 DNS 与访问控制；客户端继续拒绝非公开 IP 字面量和本地域名。不执行 PAC、SOCKS 或网站 JavaScript，系统代理检测的 Windows 实机完整验收仍未完成。

## 安装

```sh
npm install -g nekomimi@0.1.4 --registry=https://registry.npmjs.org
```

最低 Node.js 版本为 22.19.0。
