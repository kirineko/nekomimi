# Nekomimi 0.1.3

## 新增与改进

- 新增独立 `web_fetch`：搜索后读取原网页，也支持直接读取公开 URL；提供可读正文、来源、摘要回退和截断提示。
- 浏览器标签页与页面共用 Nekomimi 猫耳图标，安装包包含图标资源。
- 新增可观测的 DeepSeek Web Search、文件浏览与变更对比，统一工作台右侧面板。
- 新增独立运行诊断，保留 Journal 权威历史和失败证据边界。

## 正确性与边界

- 网页响应证据按字符编码解码、脱敏后保存，成功、失败和取消采用同一路径。
- 修复网页行内代码和表格的 Markdown 保真。
- 抓取仅支持匿名公开 HTTP(S) 文本资源；跨源重定向需要显式读取，不执行网页 JavaScript。支持取消、资源限额和离线历史查看。

## 安装

```sh
npm install -g nekomimi@0.1.3 --registry=https://registry.npmjs.org
```

最低 Node.js 版本为 22.19.0。

## 本地验证

141 项单元/集成测试、11 项浏览器测试、7 项发布元数据测试、类型检查、构建和安装包验收已通过。OpenSpec 主规格已同步，已完成变更已归档。远端 CI 和 npm 发布结果在发布后单独记录。
