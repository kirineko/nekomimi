# Nekomimi 0.1.5

## 变更

- 移除 `web_fetch` 工具、调用指导、服务端 `webFetch` 选项及网页抓取、HTML 提取和代理检测实现。
- 移除 `htmlparser2`、`ipaddr.js`、`undici` 三项直接依赖及无其他引用的传递依赖，共减少 8 个包。
- 保留 `web_search`，旧抓取记录的来源、状态、截断信息与附件仍可查看、导出和导入。
- 构建前清理旧产物，安装包不再携带抓取模块；更新当前使用文档与安装包验收。

## 兼容性

这是一次工具移除：调用方应停止配置 `webFetch` 或调用 `web_fetch`。过时调用按未知工具处理。旧历史及证据不修改，不会自动重新抓取或检测代理。

## 安装

```sh
npm install -g nekomimi@0.1.5 --registry=https://registry.npmjs.org
```

最低 Node.js 版本仍为 22.19.0。

## 验证

复审未发现可操作回归。类型检查、105 项单元/集成测试、13 项浏览器测试及 7 项发布检查通过；OpenSpec 已同步归档，17 项主规格严格校验通过。安装包已通过全局 CLI、Web、配置、工作区隔离、高亮及离线导出导入验收，确认不包含抓取模块。实际发布结果在完成后记录。
