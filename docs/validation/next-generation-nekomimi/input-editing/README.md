# 10.9 引用输入与扩展交互迁移

本阶段完成双工作台的引用编辑和等待回答表单迁移。任务 10.9 仍未完成，整体仍为 77/89；默认入口、旧界面清理及完整浏览器门槛尚未交付。

## 实现

- 工作和创造会话使用共享引用编辑器，支持文件/目录候选、目录导航、路径分页、原子引用块删除/撤销、带验证的剪贴板、原生输入法及命令补全。查询、选择和剪贴板恢复均携带当前会话身份。
- 服务端依据绑定目标检查目录有效性；创造目录失效或会话不存在时拒绝请求，不回退到工作项目。引用只传路径，不预读文件内容或扩大工具权限。目标索引缓存有界，并随服务关闭清理。
- 草稿文本保持既有持久化方式；同窗口路由切换还保留经过验证的引用块。浏览器完整重载后保留序列化路径文本，不声称跨重载恢复结构化引用块。
- 查询、选择和剪贴板迟到结果不能覆盖已变化的输入；50ms IME 确认保护、长按去重、提交失败保留输入和鼠标发送后的编辑焦点继续保留。
- 扩展等待表单接入工作/创造输入区，使用统一控件、安全文本和当前会话筛选。加载/回答在卸载时中止客户端请求，不将断线当回答；错误显式重试复用相同 commandId；同步提交锁避免同一组件重入；已回答表单不会被迟到轮询重新插入。
- 已删除/无权工作会话不挂载输入和交互轮询。短屏限制编辑器高度，长引用在编辑区内滚动；编辑时滚动展示完整发送行，不转移焦点。新工作台移除默认 body 外边距，避免 100dvh 布局底部被裁切。

## 失败修复

1. 首轮 21 项中 16 项通过，5 项停在候选名称匹配：文件名与类型之间无读屏空格。补齐显式空格后，候选识别通过。
2. 下一轮 21 项中 20 项通过，短屏长引用将发送按钮挤出视口。限制编辑区短屏高度并允许主区滚动，短屏用例及最终统一回归通过。
3. 接入表单后的 35 项运行中 33 项通过：扩展夹具没有缩窄 Json 类型而被完整类型门禁正确拒绝；无效会话新增重复错误来自不应挂载的交互轮询。分别修正夹具类型检查和失效会话输入生命周期，之后统一 36 项全部通过。
4. 人工截图复核发现旧的 toBeInViewport 默认断言只要求部分可见，短屏发送按钮仍被底部导航遮挡。改为 ratio:1，补齐编辑时完整发送行定位；该严格断言又发现桌面底部裁切来自默认 body 外边距。移除新工作台范围内的默认边距，随后最终同一构建 36 项包含严格可见性与取消扩展表单检查全部通过。
