新工作台接入只读主题目录、明确预览/取消、项目与用户默认范围确认、跟随用户默认和顶部恢复默认界面。独立创造会话通过 runtime-ui 的 session 参数读取原目标；应用与观测使用相同会话，不能落到服务项目。主题偏好和资源版本冲突有 409 可操作提示，不自动重试。

新增语义样式生成器覆盖字体/回退、字号/字重/行高、配色、控件间距/圆角、气泡、阴影、本地背景及动效。输入沿用受限 JSON 契约并额外限制嵌入素材 URI，只使用新 tokens、共享控件 data-slot 及消息 data-row-kind，不接受选择器或脚本。没有声明的颜色保留宿主明暗值，减少动效会关闭主题动画。

预览和页面浏览不保存偏好、不记录宿主观测；明确应用后实际挂载样式才写 stylesheet-mounted 观测。资源撤权、不可用或目录失败时撤下样式。恢复入口保留固定可读颜色，立即移除样式后尝试按最新修订保存默认；失败明确提示并以 sessionStorage 保持本窗口回退，刷新后仍可操作，明确预览或应用才解除。
