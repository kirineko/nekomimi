# 10.4 能力包管理进展

能力包独立页接入全局目录及绑定创造目标路由。浏览目录不运行静态检查或工厂；准备好的候选在用户点击后检查、展示文件与完整/新增权限，确认范围、内容摘要和安装修订后安装。回退先检查实际旧内容，使用相同确认与修订门禁。

已安装条目支持显式导出和卸载。导出校验内容摘要，不包含授权、凭证、目标绑定与运行状态，使用排他文件发布防止并发覆盖。卸载比较审阅内容与安装修订，排队保存同一修订并在实际提交时再次检查，不能静默删除并发更新。缓存清理列出范围与请求丢弃的候选，保留安装、回退、历史与工作流引用，并展示真实删除/保留计数。
