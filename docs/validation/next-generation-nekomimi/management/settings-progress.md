# 10.4 基础设置进展

当前未提交工作树快照；任务 10.4 仍待主题等管理入口整合，未勾选。

工作与创造工作台增加基础设置文字入口，模型管理页提供默认凭证链接。页面支持默认模型与服务地址、搜索模型/服务地址/开关、自动整理上下文开关，以及默认 DeepSeek 凭证的保存和确认清除。配置修改先进入固定草稿及修订的确认弹窗；取消零写入，保存不触发模型调用。

`GET /config` 新增 `storedCredentialConfigured` 与 `runtimeDefault`（模型、地址、凭证布尔状态、启动覆盖标志），不返回凭证。页面不用旧 `configured` 聚合状态判断默认凭证是否存在。用户清除本地密钥但启动参数仍有密钥时，两种状态分别展示；模型及端点启动覆盖也明确可见。

设置编辑草稿在查询刷新、保存失败后保留；版本冲突展示最新服务端值，须显式采用新修订并再次审阅才能覆盖。凭证输入在提交时清除；mutation 参数只存清除/保存操作类型，错误消息脱敏，不持久化密钥。清除凭证单独确认并固定授权修订；不清除其他 Provider 凭证或启动参数。
