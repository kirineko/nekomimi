# 5.6 分类、图片宿主调用及模型桥验收

已接通 `model_classify`、`model_image`；原生工具、SDK callTool 和 Codemode 使用同一 recordedTool 入口及运行调用预算。classifier/image 分别解析对应用途，显式 profile 必须同类型，不借用主模型凭证或回退 provider。模型定义来自捕获的授权扩展，类型/协议/凭证匹配后，派发前再次验证资源授权、profile 和凭证。当前公开适配协议分别为 typesafe-system-one、openrouter-images；其它协议明确不可用。上下文容量已知时按统一估算拒绝超限输入，容量未知不造数；图片输入须有对应能力。

底层只允许一个可观察的网络 attempt，不隐式重试，禁止重定向。完整原始响应与类型化结果分离；分类错误、越界概率不能作为合法答案。图片返回内容与持久附件引用。取消后的既有证据保留，不返回成功图片或继续主模型调用。工具/脚本结果只携带子模型引用，不增加顶层 usage；模型 attempt 保存已知 token，缺失字段/未核实价格为 null。辅助结果不写入主会话 context.add。

验证覆盖：直接分类、Codemode 分类、图片附件字节一致；主/辅助实际 endpoint 与凭证隔离；同 ID 多类型；撤销凭证及资源 grant 后零辅助派发；取消图片完成提交后不继续主请求；分类上下文超限零派发；分类三种答案、错误/未知用量、HTTP 错误不重试。7 个相关测试文件的 51 项中首轮 49 项通过，2 项 Codemode 既有时序测试失败；修复后对应文件 5 项全部通过，模型桥 6 项也通过。增加预算门槛后模型桥 7 项通过，共 52 项不同相关测试通过。最终类型检查、构建、43 项严格规格和 diff 检查通过。

首次测试扩展未声明 factory 参数类型、后续 fixture 调用了不存在的 state 方法，两处修复并保留失败日志。并发测试原本用 30ms 延时推断重叠，改为首批 4 个执行器同步屏障；128 次持久调用测试改为允许现有 30 秒 sandbox 截止时间及清理返回，运行时限制未改变。详见 regression-first/fixed、budget 及 types-final/build-final/specs-final 日志。

底层阶段记录见 transport.md，描述的是当时尚未接入宿主的历史快照；本报告为当前 5.6 结果。未进行真实模型调用或价格验证。5.8 写入成功、分类失败与取消远端任务的综合恢复场景仍待实施；工作台展示由 10.6 实施。
