# 10.9 可选界面按需加载阶段

2026-10-08，未提交工作树，macOS arm64 / Node.js 24.15.0 / Chrome 154.0.8037.98。

## 实现

- 管理页面、创造页面、核心候选页面使用明确动态入口；文件/变更、调用证据及导出内容首次打开时加载。轻量弹层外壳保留在宿主。
- 统一局部加载提示、关闭与重试，错误边界隔离可选组件渲染失败。成功模块在当前页面内复用；显式重试通过 Vite manifest 解析同源 JS 入口并附带新查询参数，避免复用失败的原生 import。
- 关闭后迟到的加载结果只缓存模块，不重开界面或抢焦点。文件加载关闭回到证据选项卡并聚焦；会话管理页面加载关闭返回原会话。
- 导出运行时禁用；会话切换/关闭中止下载并清除本次脱敏输入。新增常驻关闭按钮避免异步内容替换导致焦点丢失。
