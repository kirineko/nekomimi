# 核心后台操作与页面确认

10.2 进行中。macOS arm64 / Node.js 24.15.0，未提交工作树。核心后台操作已接入，扩展可信模拟及预览任务的完整取消/状态尚待整合，因此未勾选父任务。

## 已实施

- 页面显式读取构建计划，展示输入 hash、目标宿主、Node/npm/平台、实际命令、脚本与预算；确认可信执行后才提交。独立验证单独选择已通过构建，确认确切产物摘要及隔离执行授权。
- 首次接受前复核 build-plan 或产物准入，输入变化 409 拒绝且不写任务接受记录。重复命令先读取原收据，同 ID 不同输入冲突，不重新执行或自动重试。
- Web 操作 Journal 记录接受、取消请求及结果链接；原 CoreBuilds/CoreValidations Journal 保持进程/产物事实权威。历史接受无终态不重新派发；异常不能证明清理时显示 unknown。
- 前端轮询原任务及执行日志；导航不会停止或重启。取消先持久化请求，再触发已有进程组清理，实际确认后展示终态。
- 活动操作阻止核心切换；服务关闭或租约失效停止它们。候选目录失效时，任务只读和取消入口仍可用，不因为开发目标损坏而失去停止能力。会话删除门禁同时覆盖核心操作和静态验证，活动任务所属会话不能被删除。
