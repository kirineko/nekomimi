# 扩展验证取消基础

10.2 仍在实施。本批只完成持久后台模拟/预览任务所需的执行层取消和准确终态，不宣称后台任务/页面取消入口已接入。

## 改动

- ExtensionProcess.start 接收可选取消信号，派发前复核并在初始化 RPC 期间停止所属进程；取消不必等到工厂注册命令。停止失败携带 cleanup=unknown，调用者不能推断已经退出。
- trialExtension 将信号传至工厂初始化；失败先关闭宿主，再记录 simulation 终态。清理失败或先前清理未知时记录 unknown；确认清理后才可记录 cancelled/failed。
- 面板候选预览在启动、附着和交付边界复核信号；失败或取消撤销已生成实例。清理确认丢失记录 unknown，不保留可继续打开的“成功预览”。预先取消不准备或运行预览。
- 验证结果契约增加 unknown，阶段证据和真实清理结果一致。取消不能回滚可信代码已发生的外部效果。
