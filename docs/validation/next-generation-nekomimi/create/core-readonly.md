## 行为

- 核心创造目标提供可刷新深链接 `/v2/create/session/:sessionId/core`，只读 API 拒绝工作会话或非核心目标，不回退默认候选。
- 准备源码时将原始文件保存为 Journal 附件，与基线的内容摘要相互核对；附件保存后再次检查原目录/副本版本，才提交 prepared。原始目录后续变化不影响差异前文。
- 基线附件映射使用无原型对象，普通源码文件名 `__proto__` 不会丢失或改变对象原型。已有候选未保留基线正文时明确提示，不从已变动的原目录推测。
- 页面展示当前源码与基线差异、目标宿主、依赖锁和构建命令；正文有单文件/全页预算与截断提示，二进制保留摘要及字节数。
- 构建和独立验证分别从现有 Journal 读取。输出附件经完整性检查后展示；历史通过并非当前产物准入。无终态显示“尚无可靠终态”，可能仍在其他进程执行，不能自动判为已停止或重跑。
- 任一构建/验证历史不可读，页面局部说明，源码差异仍可读取。日志、旧任务超出本页预算时明确提示省略数量。导航不调用 build-plan、构建或独立验证。
