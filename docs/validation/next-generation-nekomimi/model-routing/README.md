# 5.7 实验路由支持边界验收

当前仅支持明确物理模型。`routing` 省略或 `physical` 均合法；其它值在 profile 保存/恢复、模型登记、聊天宿主及辅助模型请求入口拒绝。目录显式报告物理模型。没有启用 opt-in 自动路由，因此本次不声称支持动态选择、路由后容量检查或路由费用。

验证：`test/model-routing.test.ts`、`test/model-catalog.test.ts`、`test/durable-model-service.test.ts` 共 18 项通过。覆盖实际聊天请求使用指定模型、恢复未知策略零派发且原文件不变、三类辅助操作零 attempt/零解码、不登记实验策略为静态模型。类型检查、构建、43 项严格规格检查及 diff 空白检查通过。

首次测试与类型检查失败原因是新测试漏传必需的 session 路径，补齐后通过；原始失败日志和修复后日志均保留。没有真实模型调用。分类/图片宿主执行（5.6）和综合部分失败（5.8）仍待实施。
