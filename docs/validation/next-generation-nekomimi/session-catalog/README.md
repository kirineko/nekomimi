# 10.9 会话列表与预览绑定修复

本阶段继续落实主规格中未变的会话契约；10.9 仍未完成，整体仍为 77/89。

## 变更

- 工作/创造列表按模式使用独立查询缓存，30 条分页。读取后续页时携带同一 listRevision；发生顺序冲突时重新读取第一页，不拼接不同版本。手动刷新与定时读取保持已加载窗口，失败保留已显示列表及当前会话草稿；下一页失败可显式重试。
- 恢复本地日期分组、相对活动时间、时间未知分组和完整时间按钮。每 30 秒更新分组，键盘/触摸可展开完整时间，Escape 或移走焦点收起；标题截断，状态使用文字。
- 创造深链接直接读取所选会话快照，确认 create 模式，不从列表首屏推断会话存在性。真实 101 会话夹具证明最早会话可打开、编辑、刷新，并能逐页显示全部 101 条。
- 双工作台会话菜单复用同一受控菜单，同一列表只展开一个；失焦、外部点击、Escape 和选择会话可关闭。删除统一使用共享 Dialog：默认取消焦点、焦点恢复、遮罩关闭；删除处理中禁止重复提交及关闭。删除其他会话保留当前路由和草稿；当前会话删除后返回相应模式首页。停止运行是独立明确操作，不把取消误报为删除成功。
- 会话删除说明明确保留工作区文件、关联会话、候选和已应用能力；真实删除后夹具工作区文件保持不变。
- 搜索与手动重命名在本轮核对的既有主规格/实现中不是待迁移契约，因此没有凭推测新增 API 或静默扩大 change。

## 组合回归发现的预览问题

此前候选预览 attach 未绑定 task.sessionId，而面板文档读取已要求严格作用域，因此候选预览构建通过后浏览器仍在 10 秒后握手超时。本轮将预览实例与拥有会话绑定，读取、过期检查、驱逐与取消清理使用该身份。关闭面板先验证归属，再移除候选帧索引，避免越权失败请求破坏合法预览。

HTTP 测试证明：同目标的另一创造会话读取帧返回 403，越权关闭也返回 403，原会话仍可读取预览；没有放宽面板作用域规则。无会话的底层预览夹具仍仅支持原先无绑定的独立预览调用。
