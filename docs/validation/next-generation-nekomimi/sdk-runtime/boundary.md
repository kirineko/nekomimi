## 实现与门槛

- 实际扩展命令等待测试标记时申请新候选，收据持续 pending，活动实例和持久指针仍是旧版本；运行结束返回旧实现结果后才提交新版本，下一命令使用新实现。保留已有注册失败不替换旧版本及崩溃恢复测试。
- 项目候选预览返回活动登记 revision；应用/回退支持在授权写入前比较，回退额外校验确认时的目标 hash。旧确认冲突不改授权或活动指针。
- 能力包同样提供 project/user 各自登记 revision，安装与回退复核；回退不会把过期目标静默换成现在的 previous。管理页面提交预览/目录中保存的版本值。
- 引入 StateCompatibilityError，会话和工作区 schema 不匹配保持原值。进程桥遇到该错误后阻止该资源在当前实例中的后续宿主服务，并在回调返回前再次检查；扩展捕获错误不能将结果伪报成功。
- 实际回退场景保留 schema 2 状态，旧代码请求 schema 1 后捕获错误并尝试 write，写入仍被阻止，调用终态失败，原状态事实保留。门禁在状态访问发现不兼容时触发；不会猜测任意 Node 代码，也不撤销此前副作用。
- 既有工作流显式迁移、旧定义固定、授权撤销、进程取消及并发服务回归继续通过。
