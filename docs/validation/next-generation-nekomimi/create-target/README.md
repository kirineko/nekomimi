# 创造目标、资料与受控文件范围（任务 3.3）

创建身份和每次模型／工具派发核对目录身份及目标宿主构建、SDK 3、数据契约。宿主变化后拒绝继续；SDK 工具返回确切绑定目标，资料读取不悄悄采用其他宿主。macOS 路径别名先规范化。

创造根目录不能包含原项目、覆盖当前安装，或落在用户资源及宿主数据目录内。普通文件工具与资源写工具仍检查真实路径、符号链接与新鲜度；实际越界写入测试保留原文件。SDK 目录、安装资料及运行环境明确说明 shell 和可信 Node 扩展具有宿主 OS 权限，cwd 与模式不是沙箱。

核心目标只读检查源码包版本、锁文件根身份、源码入口和构建配置／脚本存在，JSON 输入有大小上限；缺失、版本不符或源码入口符号链接越界均拒绝。该检查不运行脚本、不下载源码、不修改安装。测试中的最小源码夹具只证明准入行为，不证明完整源码、可信构建、健康启动或切换可用；这些由第 8 组实际快照与验收完成。

证据采用 macOS arm64、当前未提交工作树、假模型 transport 和真实本机 HTTP／工具进程，无真实模型调用。

- `final-tests.log`：6 文件 88 项相关契约通过（会话身份、模式、SDK、文件工具及提示）。
- `final-admission-tests.log`：最后增加默认用户资源保护与源码 JSON 大小限制后，9 项准入测试通过；与上述有重叠。
- `admission-types.log`、`admission-build.log`：最终类型与构建通过。
- `context-regression.log`：运行环境权限说明增加后，上下文预算、工作流和扩展服务 3 文件 11 项回归通过。
