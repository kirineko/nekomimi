# 10.3 摘要准备和创造输入

2026-10-08；macOS arm64 / Node 24.15.0；未提交工作树，基线 HEAD be50c5a8a1557ef160056b964cd29e65b395685d。

## 实现

交接预览提供单独的摘要模型授权。生成结果只展示，不改变交接；明确采用后写入摘要草稿并移除旧预览/确认，必须重新预览和确认。准备使用独立命令和固定 payloadHash；失败后重取沿用同一命令，不自动重复调用模型。取消发送到准备任务，直到请求结束才退出运行状态。修改或离开预览中止 HTTP 请求，由服务端断开信号取消准备；迟到结果不会写入新草稿。无凭证、源版本变化、拒绝结果都局部显示，不创建交接。

提取 SessionComposer 为工作/创造共用输入控件；创造草稿按 mode/targetId/sessionId 保存，命令目录携带 session 参数，交付引用仅工作模式显示。创造主区接入只读快照/SSE、结果和明确停止入口。进行中禁止再次发送但保留下一轮输入。任务只有用户明确发送才派发到绑定开发目标，进入页面/接收交接/刷新不提交。

输入标签使用组件独立 ID；创造任务与交付卡使用不同 key。回执清除仍使用最新草稿读取，避免跨导航覆盖后来输入。
