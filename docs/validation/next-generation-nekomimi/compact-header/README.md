# 10.9 紧凑头部、外观与显示恢复

2026-10-08，未提交工作树，macOS arm64 / Node.js 24.15.0 / Chrome 154.0.8037.98。

## 行为

- 统一“更多操作”入口包含外观与导出。明暗切换、默认界面恢复和“显示扩展内容”均位于外观窗口；高级主题作用域初始折叠。核心版本恢复保持独立，因为它涉及服务版本与进程恢复，不是界面显示偏好。
- 外观 Escape/遮罩关闭取消未保存主题预览；嵌套确认只关闭最上层，焦点回到正确入口，草稿保持。宿主恢复控件在主题管理分块失败时仍可使用。
- 显示扩展内容为当前窗口偏好，刷新后保留。关闭会卸载打开的插槽、记录面板和扩展页面，清理草稿桥请求；恢复显示不自动重新挂载。默认恢复同时隐藏扩展，不修改扩展授权，不重放工具或任务。
- 导出无会话、任务运行时禁用；其他客户端开始运行时关闭已有导出窗口，运行结束后不重开。HTML/诊断包、脱敏和显式错误反馈保留；关闭恢复更多入口焦点。
- 菜单和选项卡显式使用主题颜色与无原生边框样式。导出/外观使用百分比宽高约束，保证 200% CSS 缩放实验下关闭控件可达。
