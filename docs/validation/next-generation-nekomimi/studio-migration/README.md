# 10.9 定制管理场景迁移

2026-10-08，未提交工作树，macOS arm64 / Node.js 24.15.0 / Chrome 154.0.8037.98。

## 实现与范围

`customization-studio.spec.ts` 的七项旧管理弹窗场景迁移到创造空间的独立模型、权限与工作流页面。测试使用受控只读快照与写入响应，真实启动 HTTP 服务和浏览器；模型调用入口禁止请求，无真实模型调用。

迁移发现并修复实际字段验证缺陷：模型配置名称的 `[a-z0-9-]` 在 HTML pattern 使用的 Unicode sets 模式下是无效字符类，浏览器忽略名称约束并发送非法名称。`model-profile-editor.tsx` 改用等价的显式连字符分支 `[a-z](?:[a-z0-9]|-){0,47}`。非法名称、无效服务地址及空请求路径均验证为零写请求；正常连字符名称可保存。

| 场景 | 新入口与断言 |
| --- | --- |
| 空状态和加载恢复 | 独立模型页错误与显式重新读取；无 Provider 时无保存入口；选择对话框 Tab 焦点约束、Escape 返回触发器；导航无写入 |
| 用途选择 | 已选项、取消无写入、失败保留原摘要且禁用自动重试、显式重新审阅后仅改变 work 用途，辅助用途不变；返回页面读取持久结果 |
| 草稿与凭证部分成功 | 延迟目录刷新完成时保留草稿和输入焦点；凭证成功而 profile 冲突后清除密钥，显式采用当前修订，凭证只写一次；取消清空编辑区 |
| 保存中离开 | 请求发送后离开页面，返回只读取已保存结果，写入恰好一次 |
| 响应式与视觉 | 1440px、390px、360px 及 720px/2x device scale 下模型、编辑、长资源诊断、未知工作流可读，无页面级横向溢出；减少动效生效 |
| 字段与未知凭证 | 非法字段不写入；最终请求路径可见；凭证写入不确定后清除密钥，空密钥不再发请求，重新输入才允许显式继续 |
| 资源诊断 | 运行中延后提示、失败加载收据、发现/活动版本及遮蔽来源分别可见，查看零写入 |

原弹窗页签和自定义选项列表由路由导航及带确认的原生 select 替代；不保留旧组件专用的搜索框、Home/End 列表实现或关闭按钮断言。当前检查 select/change、Tab/Shift+Tab 和 Escape 的宿主语义；macOS 系统原生选项弹窗内部的按键选择未由本轮自动化证明。2x device-scale/viewport 仿真不冒充原生浏览器缩放。
