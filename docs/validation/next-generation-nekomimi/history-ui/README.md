# 10.7 历史阅读与响应式状态验收

2026-10-08，macOS arm64 / Node.js 24.15.0 / Chrome 154.0.8037.98。当前未提交工作区，基线 HEAD 见 manifest。任务 10.7 完成，总进度 76/89。

## 实现

- work/create 使用相同的会话 SSE/双向分页控制器，数据窗口最多 180 行；服务端每页 60 行。共享 reducer 的重复/迟到事件测试现在覆盖实际生产合并路径。
- TanStack Virtual 仅挂载可见及 overscan 行正文。轻量行容器和测量缓存保留当前窗口中的稳定身份及高度，不把 180 行正文全部保留在 DOM。焦点/选中文本所在行保持挂载，选择时不自动换页。
- 单一滚动协调器处理图片、字体、面板及分页引起的高度变化；虚拟器不再独立补偿。历史导航固定高度；手动阅读、迟到分页、失败重试与明确返回最新使用现有可靠导航语义。
- 交付卡返回定位与普通跟随互斥；点击返回最新后停止交付定位。
- 宽窄屏保持同一分栏组件树，导航/详情仅改变展示方式。真实扩展 iframe、局部 JSON 编辑、草稿和文本选择不会因断点切换重新创建。分栏比例从本地偏好校验后恢复。
- 历史行挂载只读取保存数据，虚拟重挂载不发面板/工具/模型执行请求。完整旧页面清理和全部 slot/bridge 仍属于 10.9。
