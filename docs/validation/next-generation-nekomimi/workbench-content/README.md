# 10.9 工作台内容、文件与导出迁移

本阶段补齐默认入口切换前的真实用户功能，**10.9 仍未完成**，整体保持 77/89。新工作台仍在 `/v2`；没有通过删除旧测试来掩盖功能缺失。

## 已实现

- 新时间线使用共享安全 Markdown 渲染器与有界语法高亮 worker，恢复标题、链接、表格、代码块；HTML 不执行，外部图片保持占位。样式使用新 tokens，明暗语法颜色独立于旧工作台 CSS。
- 工具结果恢复输入、结果、按需原始附件及已确认文件 diff；未确认或缺失证据不伪装成当前文件内容。
- 已保存面板匹配原资源及版本，用户明确打开后才挂载并使用保存的 props；关闭、刷新和虚拟行重挂载回到文本回退。不可用的原版本不替换为新实现。
- 文件树、变更列表及 diff 使用共享控件和新样式，不依赖旧 file-browser/changes-list/diff-view 选择器。保留真实文件服务、隐藏文件、目录展开与分页、键盘入口、本机打开和 diff 分页。
- 工具 diff 的定位按钮切到同工作会话的文件区域；窄屏打开导航/详情。定位不会打开本机程序，打开仍需要明确双击或按钮。
- 工作与创造会话均有“导出会话”文字入口，提供 HTML、诊断包及脱敏字段；关闭取消未完成请求并清空脱敏输入，错误保留当前输入供修正，不把下载动作写回 Journal。
- 修复面板 HTTP 并发乱序：同实例的服务端阶段串行，用户草稿确认独立等待，因此状态订阅仍能继续。延迟夹具复现修复前 sequence 3 先成功、sequence 2 返回 500；修复后两请求成功。

## 首次失败与修复记录

1. 内容测试的 `pre` 定位同时选中 Markdown 与工具原文；改为限定新富文本区域，未放宽内容断言。
2. 本机文件打开测试使用 `/var` 临时目录路径，服务正确返回 `/private/var` 规范化路径；改为 realpath 比较。
3. 一次已有插槽用例 45 秒超时，固定构建复跑通过；没有足够证据把那一次超时确定归因。随后另建 HTTP 延迟夹具，明确证明并修复请求序号乱序，前后日志与去除请求身份信息的序列摘录均保留。
4. 导出标签原先包裹 textarea，文本更新影响精确标签定位；改为独立 label/htmlFor。
5. 导出夹具误以为脱敏诊断包包含 Journal；按生产契约验证 view.json、redacted/resumable 标记，并另下载未脱敏包验证 Journal。
6. macOS tar 包含 AppleDouble `._manifest.json` 元数据项，后缀匹配误读二进制；改为精确路径分量匹配实际 JSON 文件。没有以忽略解析错误替代检查；跨平台归档与元数据范围仍需在安装包/隐私验收中核对。
