并修复截图反馈中的资源加载问题（CSP 拦截动态样式、缺少 preflight）。

- 归档与发版需另行授权，本报告不触发。

## 残余风险与未测项

1. **Node 22.19.0 未实测**：本机无该版本（仅 22.12.0 / 20 / 24）；验收在 Node 24.15.0 完成。发版前须在最低支持版本上重复安装包验收。
2. **Windows 未测**（项目约定暂不处理）。
3. **默认并发下 `npm test` 在本机会因负载超时**（Spotlight 占用）；低并发 796/796。CI 上应直接验证。
4. **极端缩放边界**：360px + 200% 缩放时顶栏与头部折成多行，“发送”需滚动到达（无遮挡、无横向溢出）。
5. **全局排版基线并入 `@layer base`** 使工具类首次真正生效，按钮字重/标题字号与旧版有细微差异（更接近设计意图）；
   已对亮/暗、宽/窄截图复核，但外部扩展面板内的宿主样式不受影响（iframe 隔离）。
6. 同 URL 仅 hash 变化会触发“重新授权后自动刷新”（产品行为）；依赖旧行为的外部脚本需改为完整导航。
7. 保留的开发性入口：`/dev/ui` 演示页仍使用“更多操作”文案示例。

## 偏差记录

- `handoff.*` 事件不进入时间线投影，SSE 驱动失效改为按快照 seq 前进（300ms 合并）；设计中的“事件名匹配”不可行。
- 设置总览使用 `/work|create/settings-hub` 而非改写既有 `/settings`（避免破坏“基础设置”深链接）。
- 每轮“查看证据”仅在该轮存在运行/调用时显示；会话头部不再常驻“调用证据”。
- 管理页统一由 `ManagementMain` 作为唯一 `<main>` 与滚动容器。
