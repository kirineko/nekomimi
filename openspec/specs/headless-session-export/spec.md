# headless-session-export Specification

## Purpose

提供无需浏览器或终端界面的任务执行与会话检查方式，让用户显式继续历史任务，并能够通过完整诊断包或离线阅读文件审查记录而不触发新的模型和工具操作。

## Requirements

### Requirement: 无界面运行与继续

系统 SHALL 支持 headless 提交任务、结构化输出、取消及显式继续已有会话；同一会话拒绝并发写入。

#### Scenario: 无界面运行与继续验收

- **WHEN** 一个会话已有活动 run 时再次提交
- **THEN** 第二次提交返回明确冲突，原 run 仍可观察和取消。

### Requirement: 无副作用回放

系统 SHALL 在回放或导入检查时只恢复状态，不请求模型或执行工具；继续任务需要显式提交。

#### Scenario: 无副作用回放验收

- **WHEN** 读取包含未完成 shell 的诊断包
- **THEN** 显示未完成状态，没有网络模型请求或 shell 启动。

### Requirement: 完整及脱敏导出

系统 SHALL 导出带 hash manifest 的诊断包和自包含 HTML；脱敏包明确标记删减且不可精确继续。

#### Scenario: 完整及脱敏导出验收

- **WHEN** 导出含敏感任务内容与附件的会话
- **THEN** 脱敏副本不改变原始记录，完整包携带所有引用附件，删减包可识别其限制。

### Requirement: 离线 HTML 安全

系统 SHALL 将不可信文本转义并隔离，离线导出不得依赖外部资源或执行模型提供的脚本。

#### Scenario: 离线 HTML 安全验收

- **WHEN** 工具输出包含 script 标签或恶意 HTML
- **THEN** 离线打开仅展示文本内容，未执行注入脚本或请求外部资源。

### Requirement: 离线会话阅读

系统 SHALL 导出带 Nekomimi 品牌、会话标题、轮次导航和中文状态的自包含 HTML，默认按执行顺序展示用户消息、Markdown 回答、工具调用与配对结果、文件 diff。推理文本、长输出、统计和原始 JSON SHALL 分层展开，保留原始证据定位；不得将响应字节块当成独立回答。

#### Scenario: 多轮含工具会话

- **WHEN** 用户离线打开多轮、含工具和 Markdown 的导出
- **THEN** 无需服务或网络即可通过目录定位轮次、阅读回答与工具结果并打开原始证据，窄屏内容不横向撑破页面。

#### Scenario: 失败、中断与删减

- **WHEN** 导出含失败、未知结果或脱敏内容的历史
- **THEN** 阅读视图明确保留相应状态与脱敏限制，不编造回复、成功结果或缺失统计，源 Journal 不变。

#### Scenario: 不可信 Markdown

- **WHEN** 历史包含脚本、HTML、危险链接或远程图片
- **THEN** 导出仅安全呈现内容，不执行注入脚本、不自动请求外部资源；原始证据仍经过相同脱敏处理。
