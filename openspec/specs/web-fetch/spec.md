# web-fetch Specification

## Purpose

为模型和用户提供读取具体公开网页的专用工具，使搜索后的原文核对和指定 URL 阅读具备可读正文、清晰来源、可检查的失败与截断状态，并以持久化证据支持无需重新联网的历史查看。

## Requirements

### Requirement: 独立抓取工具
系统 SHALL 提供仅接收 url 的 web_fetch 工具；抓取本身无需搜索凭证，搜索关闭时仍可用。工具指导 SHALL 说明精确 URL 读取、来源引用和外部内容不可信，不自动遍历搜索结果。

#### Scenario: 直接读取 URL
- **WHEN** 模型使用用户提供的 URL 或搜索结果 URL 调用工具
- **THEN** 系统仅抓取指定资源，返回来源与可读结果，网页中的指令不得改变工具配置或触发额外工具执行。

### Requirement: 可读内容和元数据回退
系统 SHALL 提取 HTML 标题及可见正文，保留标题、列表、代码和简单表格结构，移除脚本、样式和隐藏内容。正文为空或仅为已知加载/启用 JavaScript 占位文本时，SHALL 按 description、og:description、twitter:description 顺序回退；有意义的短正文优先于元数据。回退 SHALL 明确标识为页面摘要，空结果明确标为空。

#### Scenario: 页面摘要与短正文
- **WHEN** 页面仅有 Loading 且存在 description，或页面含有短正文及 description
- **THEN** 前者返回已标识的页面摘要，后者保留短正文且不重复附加摘要。

#### Scenario: 文本与格式
- **WHEN** 获取普通 HTML、纯文本、JSON 或 XML
- **THEN** HTML 返回可读结构且不执行脚本、不请求图片；其他受支持文本保留正文，二进制类型明确失败。

### Requirement: 编码与资源限制
系统 SHALL 支持 gzip/deflate 压缩和声明的字符编码，不重复解压。默认整个网络操作超时为 30 秒、解压后体积上限为 2 MiB、完整模型输出上限为 30,000 UTF-16 单位；SHALL 分别报告响应体与输出截断，恰好到达体积上限不误标截断。HTML 提取 SHALL 限制嵌套深度与输出膨胀，超出解析边界明确失败。

#### Scenario: 压缩与限额
- **WHEN** 压缩文本解压后超过上限或可读文本超过输出上限
- **THEN** 停止超额读取并明确标记相应截断，已保存文本可通过证据入口继续读取，不声称保存了未下载部分。

#### Scenario: 取消和错误
- **WHEN** DNS、连接或响应读取阶段被取消、超时，或发生解码错误、HTTP 错误
- **THEN** 停止本地操作且不自动重试，记录明确终态和已取得证据，不把错误页面当作正常完整结果。

### Requirement: 匿名公开网络边界
系统 SHALL 仅接受无内嵌凭证的 HTTP(S) URL；直连时拒绝非公开地址及混合公开/私有 DNS 结果，连接目标 SHALL 与校验地址一致。采用用户已配置的可信代理时 SHALL 由代理解析域名，客户端仍拒绝非公开 IP 字面量、localhost 和本地域名；代理最终 DNS 与访问控制由可信代理负责。每次重定向 SHALL 重新判断路由与边界，最多自动跟随五次同源跳转；跨源跳转返回目标供显式新调用。目标请求 MUST 不附带模型密钥、浏览器 Cookie 或目标认证，代理认证仅发送给代理且不进入 Journal、模型结果或客户端。

#### Scenario: 目标与重定向
- **WHEN** URL 指向回环、内网、特殊用途地址，直连 DNS 返回混合公开和私有地址，或重定向跨源
- **THEN** 禁止向被拒绝目标发送请求；跨源结果提供目标地址及阻止原因。

#### Scenario: 代理与 Fake-IP
- **WHEN** 用户配置了可信 HTTP(S) 代理且请求公开域名
- **THEN** 不因本机 Fake-IP 解析结果拒绝请求，代理负责域名解析；不放行直接输入的保留网段地址。

### Requirement: 抓取证据与展示回放
系统 SHALL 将请求 URL、最终 URL、HTTP 状态、内容类型、提取来源、响应体及输出截断状态与证据引用关联到工具调用。Web 卡片 SHALL 展示来源、状态、摘要回退和截断信息，并提供完整已保存证据入口；模型文本与卡片的截断状态一致。历史重开、导入、回放及导出查看 MUST 不发起抓取，普通抓取不计为模型调用。

#### Scenario: 历史与继续阅读
- **WHEN** 抓取完成后重开或导入会话，或读取截断输出的已保存文本
- **THEN** 原有状态和证据仍可访问，网络调用次数不增加，尚未保存的响应后半段不被描述为可恢复。

### Requirement: 响应证据字符编码与脱敏
响应证据 SHALL 按源字符编码解码后脱敏，以 UTF-8 保存并标记源编码和保存编码；接收字节数 SHALL 保持原始计量。成功、HTTP 失败及取消路径 MUST 使用相同脱敏规则。未知字符编码时 SHALL 记录证据省略原因，不保存未经安全脱敏的原始响应。

#### Scenario: 非 UTF-8 敏感响应
- **WHEN** UTF-16LE/BE 等响应包含已配置的敏感文本，随后调用成功、失败或取消
- **THEN** 响应 artifact、提取文本及导出不包含该敏感文本，响应 artifact 明确标记脱敏和 UTF-8 表示。

#### Scenario: 未知字符编码
- **WHEN** 响应声明不支持的 charset
- **THEN** 工具失败且记录源响应元数据与证据省略原因，不保存无法安全解码的字节。

### Requirement: 自动代理路由
系统 SHALL 优先遵循 web_fetch 专用的显式直连或代理覆盖，然后使用环境代理，再检测 macOS/Windows 已启用的系统静态 HTTP(S) 代理；无配置保持直连，Linux 使用环境配置；仅开启自动发现但无具体代理或 PAC 配置不视为已启用代理。系统 SHALL 支持 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY 的 HTTP(S) 地址及 NO_PROXY；大小写变量同时存在时小写优先。命中绕过列表 SHALL 使用完整直连校验。代理设置不改变模型工具参数或其他模型/API 请求。

#### Scenario: 无代理与覆盖
- **WHEN** 没有启用代理，或用户显式选择直连
- **THEN** 使用原有直连路径，显式直连忽略环境和系统代理。

#### Scenario: 启用与绕过
- **WHEN** 存在有效环境代理或启用的系统代理，且 URL 未被绕过
- **THEN** 通过该代理请求；环境配置优先且不被系统设置覆盖，NO_PROXY 域名、后缀、端口和通配全绕过按文档匹配。

#### Scenario: 不支持或不可用
- **WHEN** 用户配置的代理不可连接、类型不支持，或仅配置 PAC/SOCKS
- **THEN** 返回准确错误并停止，不静默直连、不执行 PAC 或尝试其他代理；未取得响应不伪造 HTTP 状态。

### Requirement: 通用 HTTP 兼容与验证页
系统 SHALL 使用统一浏览器式请求头，保持已有压缩、编码和摘要回退行为，不针对单一网站改写 URL 或调用专用接口。响应明确带网站验证标志时 SHALL 分类为需要浏览器验证，即使 HTTP 为成功也不把验证页当正文；普通 403 SHALL 保留为 HTTP 拒绝，不猜测为验证码。

#### Scenario: 验证与普通拒绝
- **WHEN** 响应包含 cf-mitigated: challenge 或只是普通 HTTP 403
- **THEN** 前者提示网站需要浏览器验证，后者保留 HTTP 403；两者均保存可安全脱敏的响应证据，不自动重试。

### Requirement: 路由证据与取消
系统 SHALL 在 Journal 记录每跳的直连/代理模式与配置来源，不保存代理 URL、账号或认证材料；失败记录可理解的分类。DNS、系统检测、代理连接及读取 SHALL 受统一超时和取消控制，回放不重新检测代理或联网。

#### Scenario: 取消与重放
- **WHEN** 检测代理或代理请求时取消，随后导出并重开会话
- **THEN** 不继续请求，已有路由和终态可回放且不再执行网络操作。
