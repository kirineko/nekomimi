# prompt-context-provenance Specification

## Purpose

为每次模型请求提供确定性的提示词与上下文来源说明，使用户能够从最终输入回溯到指令、工具定义和历史记录，并理解输入顺序及内容变化的原因。

## Requirements

### Requirement: 按工具贡献提示
系统 SHALL 按最终实际启用的内置、扩展与 MCP 工具组装 schema、简短用途摘要和提示指导，稳定排序并去重，记录来源、内容版本、资源 revision 及存在时的能力包锁定版本；禁用工具 SHALL 同时撤销其专属提示及依赖该工具的资源操作指引，不改写旧运行记录。共享指导 SHALL 在仍有有效贡献者时保留，并能追溯所有有效贡献者。

#### Scenario: 按工具贡献提示验收
- **WHEN** 关闭 edit 工具后重新组装
- **THEN** edit schema 及其专属指导均移除；相同输入重复组装结果一致。

#### Scenario: 扩展版本切换
- **WHEN** 自定义工具更新后成功重载或被停用
- **THEN** 下一运行的 schema 和指导与活动资源版本一致，历史请求仍指向原摘要。

#### Scenario: 限制定制工具集合
- **WHEN** 调用方仅允许基础工具，排除 resource_read 和定制管理工具
- **THEN** 当前操作指引不要求调用这些工具；共享基础指导保留，旧历史中的工具名称不被删除或重写。

### Requirement: 上下文追溯
系统 SHALL 为每次请求保存上下文 revision、有序节点引用、内容 hash 与来源，并保留原始历史；Skills、Rules 和扩展上下文贡献 SHALL 包含资源身份、实际内容版本和适用作用域，不把曾经加载等同于当前请求已包含。MCP 资源/提示模板、工作流步骤结果和 Provider 投影 SHALL 保存内容及参数来源、实际注入角色、固定版本与转换记录；远端通知和包更新不得偷换已捕获的请求内容，也不授予执行权限。

#### Scenario: 上下文追溯验收
- **WHEN** 用户输入、显式项目指令及裁剪的工具结果被发送
- **THEN** 每项输入都可定位来源和顺序，工具结果可回溯完整证据。

#### Scenario: 规则和技能更新
- **WHEN** 同一会话加载新 Skill 或不同目标的目录规则并发起模型请求
- **THEN** 请求证据指向实际正文版本与作用域，旧正文仍可检查，未进入当前请求的内容不显示为已生效。

#### Scenario: MCP 提示与工作流输入
- **WHEN** 工作流读取 MCP 模板并把结果用于另一个 Provider 的模型步骤
- **THEN** 可从最终请求追溯模板参数、原始消息、实际注入级别、步骤输入和 Provider 转换，原始内容及历史不被重写。

#### Scenario: 更新后的指导撤销
- **WHEN** 用户停用包含 Skill、Rules、MCP 和工具指导的能力包
- **THEN** 后续新运行撤销该包的有效贡献；旧请求继续保留原内容和作用域，停用前的历史读取不代表当前授权仍有效。

### Requirement: 压缩投影来源链
系统 SHALL 为压缩检查点保存源上下文版本、被替换节点及摘要内容摘要、保留边界、模型调用关联与前后测量；后续请求 SHALL 明确引用生效检查点及保留节点。内置与自定义 Provider SHALL 使用相同的有效上下文来源链，协议适配后继续保留实际请求证据。

#### Scenario: 检查压缩后的请求
- **WHEN** 用户检查压缩之后的模型请求
- **THEN** 能从摘要定位被替换的原始消息与摘要调用；从保留项定位原事件；实际发送内容与保存的请求证据一致。

#### Scenario: 旧记录和重放
- **WHEN** 重放无检查点的旧记录或导入包含检查点的完整会话
- **THEN** 旧记录保持原投影语义，有效检查点按证据恢复而不重新摘要；缺失或损坏引用明确诊断，不声称上下文完整。

### Requirement: 分层输入与稳定来源
系统 SHALL 区分行为规则、工具指导、项目及目录指令、按需技能和动态环境数据，为实际发送的每一层保存内容版本、来源和适用作用域；相同输入不因注册顺序变化产生不同组装。动态数据变化 MUST NOT 无谓改写稳定规则，实际规则更新和权限撤销优先于前缀稳定性；不得将本地前缀一致声称为服务端缓存命中。

#### Scenario: 环境更新与来源检查
- **WHEN** 工作目录或动态状态更新后检查下一请求
- **THEN** 实际环境与来源同步更新，未变化的固定规则内容和 hash 保持一致，旧请求仍展示原输入。

#### Scenario: 目录规则与技能正文
- **WHEN** 加载目录规则或技能后进入不同路径任务或资源被停用
- **THEN** 当前指令明确其来源和路径范围，停用贡献不再作为有效指令；历史读取仍作为历史证据存在。

#### Scenario: 资源目录过大
- **WHEN** 可发现资源超过模型可见目录预算
- **THEN** 保留必要规则和可用查询入口，明确目录省略状态，不能静默截断强制规则或声称目录完整。
