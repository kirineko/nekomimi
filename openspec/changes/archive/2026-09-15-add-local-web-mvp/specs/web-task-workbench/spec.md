## Purpose

提供可日常使用的浏览器任务工作台，将多会话导航、任务输入、执行反馈、工具结果和停止后继续整合为清晰闭环，使用户无需阅读原始 JSON 即可判断工作结果与失败原因。

## ADDED Requirements

### Requirement: 任务输入与继续

系统 SHALL 提供会话列表、多行输入、明确提交操作和结果显示，并允许终态后以新任务继续同一会话。

#### Scenario: 完成后继续

- **WHEN** 用户创建会话提交任务，完成后发送后续消息
- **THEN** 时间线保留前轮内容并新增本轮，后续模型请求使用正确历史，不创建无关联的新会话。

### Requirement: 工具结果展示

系统 SHALL 显示工具名称、参数、执行状态、有界结果及完整证据入口；文件修改展示 diff，shell 展示通道和退出信息。

#### Scenario: 输出被裁剪

- **WHEN** 工具产生超过摘要长度的内容或修改文件
- **THEN** 用户能识别裁剪并打开完整证据，文件变化可查看实际 diff，错误不显示为成功。

### Requirement: 取消与连接状态

系统 SHALL 区分运行中、取消中、已停止、失败、不完整和中断；断线 SHALL 单独标识，不冒充运行终态。

#### Scenario: 取消长命令

- **WHEN** 用户取消仍在运行的 shell 命令
- **THEN** 界面先显示取消中，只有进程停止被确认后显示已停止；恢复连接不自动继续。

### Requirement: 可用性与内容隔离

系统 SHALL 支持键盘操作输入与主要按钮、窄窗口访问会话和检查面板，并将模型及工具提供的 HTML 作为不可信文本处理。

#### Scenario: 恶意输出与窄窗口

- **WHEN** 工具输出 script 内容，用户在窄窗口打开结果
- **THEN** 内容不执行脚本，提交、取消和证据查看入口仍可访问。
