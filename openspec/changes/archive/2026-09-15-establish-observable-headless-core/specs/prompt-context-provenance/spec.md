## Purpose

为每次模型请求提供确定性的提示词与上下文来源说明，使用户能够从最终输入回溯到指令、工具定义和历史记录，并理解输入顺序及内容变化的原因。

## ADDED Requirements

### Requirement: 按工具贡献提示

系统 SHALL 按实际启用工具组装 schema 和提示指导，稳定排序并去重，记录来源和内容版本。

#### Scenario: 按工具贡献提示验收

- **WHEN** 关闭 edit 工具后重新组装
- **THEN** edit schema 及其专属指导均移除；相同输入重复组装结果一致。

### Requirement: 上下文追溯

系统 SHALL 为每次请求保存上下文 revision、有序节点引用、内容 hash 与来源，并保留原始历史。

#### Scenario: 上下文追溯验收

- **WHEN** 用户输入、显式项目指令及裁剪的工具结果被发送
- **THEN** 每项输入都可定位来源和顺序，工具结果可回溯完整证据。
