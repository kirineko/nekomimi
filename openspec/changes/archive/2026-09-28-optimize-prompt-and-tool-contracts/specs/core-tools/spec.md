## ADDED Requirements

### Requirement: 模型可见工具契约
系统 SHALL 为全部启用的内置工具提供简短用途摘要、详细调用描述及有语义的参数说明；三者职责分离，不默认复制完整描述作为系统提示摘要。描述 SHALL 与执行器的路径边界、单位、默认值、限制、前置条件和输出格式一致，不承诺不存在的工具能力。

#### Scenario: 字节读取与精确编辑
- **WHEN** 模型检查 read、edit 和 write 的契约
- **THEN** 可确定 read 使用零起始字节偏移、默认及有效上限和返回的续读偏移；edit 多项替换针对同一原始版本且唯一、不重叠；既有文件修改需读取且版本匹配，不能用模糊替换绕过失败。

#### Scenario: 实际平台与搜索工具
- **WHEN** 在不同平台或搜索开关配置下组装工具
- **THEN** 指导指向实际 shell 和可用搜索方式，包含真实 cwd、超时单位与默认值，不推荐未提供的 web_fetch、grep 或后台任务工具。

### Requirement: 失败及证据续读指引
系统 SHALL 在工具契约及相关结果中给出可执行的失败恢复和完整证据读取指引；取消、超时或结果未知不得等同于未执行，指引不得要求盲目重复可能有副作用的操作。

#### Scenario: 输出截断
- **WHEN** shell 输出超过投影限制
- **THEN** 说明退出状态和截断情况，并指导先读取输出索引 artifact、再读取通道 artifact；完整证据独立保留。

#### Scenario: 编辑冲突或取消
- **WHEN** 文件版本冲突、文本不唯一，或命令被取消且执行结果未确定
- **THEN** 分别指导重读消歧或检查实际状态，保留原失败及取消证据，不建议绕过文件保护或自动重跑未知操作。
