## MODIFIED Requirements

### Requirement: 按工具贡献提示
系统 SHALL 按最终实际启用的内置、扩展与 MCP 工具组装 schema、简短用途摘要和提示指导，稳定排序并去重，记录来源、内容版本、资源 revision 及存在时的能力包锁定版本；禁用工具 SHALL 同时撤销其专属提示及依赖该工具的资源操作指引，不改写旧运行记录。共享指导 SHALL 在仍有有效贡献者时保留，并能追溯所有有效贡献者。

#### Scenario: 按工具贡献提示验收
- **WHEN** 关闭 edit 工具后重新组装
- **THEN** edit schema 及其专属指导均移除；相同输入重复组装结果一致。

#### Scenario: 扩展版本切换
- **WHEN** 自定义工具更新后成功重载或被停用
- **THEN** 下一运行的 schema 和指导与活动资源版本一致，历史请求仍指向原摘要。

#### Scenario: 限制定制工具集合
- **WHEN** 调用方仅允许基础工具，排除 resource_read 和定制管理工具
- **THEN** 当前操作指引不要求调用这些工具；共享基础指导保留，旧历史中的工具名称不被删除或重写。

## ADDED Requirements

### Requirement: 分层输入与稳定来源
系统 SHALL 区分行为规则、工具指导、项目及目录指令、按需技能和动态环境数据，为实际发送的每一层保存内容版本、来源和适用作用域；相同输入不因注册顺序变化产生不同组装。动态数据变化 MUST NOT 无谓改写稳定规则，实际规则更新和权限撤销优先于前缀稳定性；不得将本地前缀一致声称为服务端缓存命中。

#### Scenario: 环境更新与来源检查
- **WHEN** 工作目录或动态状态更新后检查下一请求
- **THEN** 实际环境与来源同步更新，未变化的固定规则内容和 hash 保持一致，旧请求仍展示原输入。

#### Scenario: 目录规则与技能正文
- **WHEN** 加载目录规则或技能后进入不同路径任务或资源被停用
- **THEN** 当前指令明确其来源和路径范围，停用贡献不再作为有效指令；历史读取仍作为历史证据存在。

#### Scenario: 资源目录过大
- **WHEN** 可发现资源超过模型可见目录预算
- **THEN** 保留必要规则和可用查询入口，明确目录省略状态，不能静默截断强制规则或声称目录完整。
