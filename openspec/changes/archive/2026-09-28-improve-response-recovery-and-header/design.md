## Context
只读审阅本地日志发现 http 200 + response.incomplete + max_output_tokens，输出与预算一致。官方 Responses 文档明确预算包含推理与可见输出：https://api-docs.deepseek.com/api/create-response/ 。私人记录不进入测试仓库。
## Goals / Non-Goals
提高默认预算与诊断质量，收敛顶栏。不给内容过滤/网络截断无限重试，不改变显式配置，不伪造续写/工具结果。
## Decisions
用户补充要求：默认输出预算 131072（128K）、调用轮数 64；显式参数优先。输出耗尽不自动扩大预算或重试，保留 reason、usage 和预算证据；HTTP 临时失败仍受原 attempts 限制。只有 completed 响应加入上下文和执行工具，已经完成的工具不重放。
失败 presentation 优先展示任务最终状态，重试失败仅在调用检查中保留；旧英文错误映射为中文提示。继续入口填写草稿，由用户发送且尊重已有草稿冲突。
顶栏保留定制能力、文件与变更、更多。更多面板只包含外观与导出。恢复默认放入外观，取消独立恢复扩展按钮，改为显示扩展内容开关；作用域折叠入高级选项。外观组件始终挂载以保持样式，菜单内容关闭时取消预览。Escape/外点关闭并归还焦点；导出弹层有标题、说明、取消和焦点约束；主题失效时宿主菜单仍可用。
## Risks / Trade-offs
较大输出预算可能增加 token 消耗，但避免无限循环；显式限制保持。测试使用模拟服务，不代表真实模型一定可完成任意复杂任务。不同模型/代理的支持范围以显式配置为准。
## Migration Plan
旧记录只读投影兼容，不改写 Journal。新旧顶栏测试调整路径，不降低导出/恢复验证。全部相关检查后勾选任务。
