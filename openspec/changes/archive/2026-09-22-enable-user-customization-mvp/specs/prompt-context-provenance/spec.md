## MODIFIED Requirements

### Requirement: 按工具贡献提示
系统 SHALL 按实际启用的内置、扩展与 MCP 工具组装 schema 和提示指导，稳定排序并去重，记录来源、内容版本和资源 revision；禁用工具 SHALL 同时撤销其专属提示，不改写旧运行记录。

#### Scenario: 按工具贡献提示验收
- **WHEN** 关闭 edit 工具后重新组装
- **THEN** edit schema 及其专属指导均移除；相同输入重复组装结果一致。

#### Scenario: 扩展版本切换
- **WHEN** 自定义工具更新后成功重载或被停用
- **THEN** 下一运行的 schema 和指导与活动资源版本一致，历史请求仍指向原摘要。

### Requirement: 上下文追溯
系统 SHALL 为每次请求保存上下文 revision、有序节点引用、内容 hash 与来源，并保留原始历史；Skills、Rules 和扩展上下文贡献 SHALL 包含资源身份、实际内容版本和适用作用域，不把曾经加载等同于当前请求已包含。

#### Scenario: 上下文追溯验收
- **WHEN** 用户输入、显式项目指令及裁剪的工具结果被发送
- **THEN** 每项输入都可定位来源和顺序，工具结果可回溯完整证据。

#### Scenario: 规则和技能更新
- **WHEN** 同一会话加载新 Skill 或不同目标的目录规则并发起模型请求
- **THEN** 请求证据指向实际正文版本与作用域，旧正文仍可检查，未进入当前请求的内容不显示为已生效。
