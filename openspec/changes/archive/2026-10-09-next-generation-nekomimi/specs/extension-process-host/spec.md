## MODIFIED Requirements

### Requirement: 独立执行与兼容

系统 SHALL 在独立进程执行可执行扩展，协商当前宿主声明的 SDK 和进程协议版本，并提供 SDK 3 的公共工具、命令、钩子、状态、模型和声明式 UI API；未知能力 SHALL 在注册前拒绝。SDK 版本和进程协议版本 SHALL 分别检查，不要求两者采用相同版本号。进程隔离 MUST NOT 被描述为 OS 权限沙箱。

旧 V1/V2 SDK 扩展不保证兼容；不受支持的清单 SHALL 在执行工厂前拒绝，并提供当前版本资料入口，不自动改写扩展文件、加载旧代码或赋予新权限。

#### Scenario: 当前 SDK 扩展运行
- **WHEN** 用户显式授权与当前 SDK 3 及进程协议匹配的扩展
- **THEN** 公共工具、命令、钩子、状态、模型及声明式 UI 在独立进程和受控宿主服务边界内执行，身份及执行证据保持关联。

#### Scenario: 旧扩展升级运行
- **WHEN** 用户尝试启用使用不受支持 V1/V2 SDK 的扩展
- **THEN** 宿主给出版本诊断及 SDK 3 资料入口，不执行工厂、不改写原文件、不静默生成兼容层；未来能力或私有接口同样明确拒绝。
