## ADDED Requirements

### Requirement: 离线会话阅读

系统 SHALL 导出带 Nekomimi 品牌、会话标题、轮次导航和中文状态的自包含 HTML，默认按执行顺序展示用户消息、Markdown 回答、工具调用与配对结果、文件 diff。推理文本、长输出、统计和原始 JSON SHALL 分层展开，保留原始证据定位；不得将响应字节块当成独立回答。

#### Scenario: 多轮含工具会话

- **WHEN** 用户离线打开多轮、含工具和 Markdown 的导出
- **THEN** 无需服务或网络即可通过目录定位轮次、阅读回答与工具结果并打开原始证据，窄屏内容不横向撑破页面。

#### Scenario: 失败、中断与删减

- **WHEN** 导出含失败、未知结果或脱敏内容的历史
- **THEN** 阅读视图明确保留相应状态与脱敏限制，不编造回复、成功结果或缺失统计，源 Journal 不变。

#### Scenario: 不可信 Markdown

- **WHEN** 历史包含脚本、HTML、危险链接或远程图片
- **THEN** 导出仅安全呈现内容，不执行注入脚本、不自动请求外部资源；原始证据仍经过相同脱敏处理。
