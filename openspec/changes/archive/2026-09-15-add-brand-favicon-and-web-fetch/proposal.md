## Why

Nekomimi 页面已使用猫咪 logo，但浏览器标签页仍显示默认图标，品牌识别不完整。现有 web_search 仅提供标题、URL 和摘要，模型缺少读取具体网页的专用工具，无法顺畅完成搜索后核对原文或直接读取用户指定 URL 的任务。

## What Changes

- 浏览器 favicon 复用现有 Nekomimi 猫耳标识，保持品牌颜色和小尺寸辨识度；覆盖开发环境、生产静态服务及 npm 安装包，确保资源路径与响应类型正确。
- 新增独立的 `web_fetch({ url })` 工具，读取公开 HTTP(S) 网页和文本。支持搜索后选择 URL 抓取及直接读取用户提供的 URL；抓取本身无需搜索服务凭证，不自动抓取所有搜索结果。
- 主要参考 Deepy 的正文优先提取、标题提取、浏览器式请求兼容、压缩与字符编码处理，以及正文为空或仅含占位文本时的标准 description 元数据回退。保留有意义的短正文；回退结果明确标为页面摘要，不冒充完整正文。
- 再参考 dsh 的结构化可读输出、网络目标及重定向校验、取消传播和可回放展示。保留适用的标题、列表、代码及表格结构，移除非正文内容，并对转换工作量设置边界。
- 对请求时长、解压后响应体及模型输出分别设置上限；区分抓取截断与展示截断，避免截断压缩包后再解压及重复解压。初始限制参考 Deepy 的 30 秒、2 MiB 响应和 30,000 字符输出，具体计量与边界场景在设计和规格中确定。
- 保留原始 URL、最终 URL、HTTP 状态、内容类型、提取来源及截断状态。抓取证据、模型文本和 UI 元数据通过同一工具调用关联到 Journal；已保存但未全部展示的文本可通过现有 artifact 读取能力继续查看。
- 工具贡献搜索后读取原文、引用来源和将网页视为不可信数据的指导；Web 展示抓取状态和证据入口，失败、超时、取消及部分内容不被误报为完整成功。历史重开、回放、导入和导出查看不重新发起请求。

### Non-Goals

- 不加入 JavaScript 浏览器执行、登录态或 Cookie 抓取、PDF/图片解析、远程抓取服务、框架 hydration JSON 通用提取或额外模型摘要调用。
- 不替换现有搜索 provider，不扩展为爬虫或自动批量下载，不引入 dsh 插件宿主或照搬 Deepy 的 Python 运行时。
- 不重新设计产品 logo，不修改历史协议标识，不在此变更中发版。

### Research Alignment

- 对应 `spec.md` 第 2 节的参考分工：Deepy 为抓取行为的主要来源，dsh 补充边界与展示设计。
- 对应第 3.3、3.5 节的工具执行证据与持久化，第 4.2 节的工具提示词贡献，以及第 5 节的专用工具能力。
- 对应第 8.1–8.3 节的 Web 展示和本地服务边界、第 12–13 节的安装包交付与验证。

## Capabilities

### New Capabilities

- `web-fetch`: 专用 URL 抓取工具，覆盖工具可用性、正文与元数据回退、文本解码、来源记录、网络和资源边界、失败与取消、证据保存、结果展示及无副作用回放。

### Modified Capabilities

- `web-readable-presentation`: 将现有猫咪品牌一致性扩展到浏览器标签页 favicon。
- `local-web-service`: 扩展静态资源交付契约，保证安装目录中的品牌图标以正确类型返回，同时保留静态资源路径和连接授权边界。

## Impact

- 前端与静态交付：涉及 `src/web/index.html`、现有 `Brand.tsx` 的标识资源复用、Vite 资源构建和 `src/server/app.ts` 静态响应；不开放任意静态文件访问。
- 工具与持久化：涉及 `src/tools.ts`、新增抓取模块，以及现有 Journal/artifact、工具结果投影和 Web 工具卡展示。普通 HTTP 抓取作为工具证据记录，不伪装成模型调用或生成模型 usage。
- 安全和兼容：仅匿名 HTTP(S) 请求，不转发模型密钥或环境凭证；设计阶段明确公开地址校验、DNS 与连接一致性、代理边界和重定向策略。候选默认采用同源自动跟随，跨源返回目标供显式再次调用；不得仅校验初始 URL。
- 依赖：可能新增 HTML 解析或 Markdown 转换依赖；具体选择及固定版本在设计阶段验证，避免引入重量级浏览器运行时。
- 后续验证：使用确定性 HTTP fixtures 覆盖正常 HTML、短正文、Loading/description 回退、元数据优先级、纯文本、压缩及非 UTF-8 编码、错误响应、重定向、限额边界、取消和恶意 HTML；核验网页内容不作为指令、历史回放不联网、UI 与模型截断状态一致。favicon 通过实际浏览器显示、生产资源响应和安装包验收验证。
- 当前提案不代表功能已交付；后续 specs、design、tasks 和实现须保持上述范围一致。
