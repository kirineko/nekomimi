## ADDED Requirements

### Requirement: 历史文件差异语法高亮

系统 SHALL 对支持语言的已确认文件 diff 叠加源代码语法颜色，保留增删背景、符号、行号、统计、分页、复制和截断提示。具备可验证的完整历史源文件且未超预算时，删除与新增行 SHALL 分别采用修改前后的语言上下文，跨 hunk 和分页保持一致。高亮 MUST 只依赖已保存且允许展示的历史证据，不读取当前文件补造过去。

#### Scenario: 多行注释与分页
- **WHEN** 差异位于多行注释或字符串中，用户从预览展开并切换分页
- **THEN** 同一历史行语法颜色一致，两侧按各自历史上下文着色，统计和行号不因高亮改变。

#### Scenario: 新文件与当前文件已变化
- **WHEN** 查看没有旧文件的新建记录，或磁盘文件在执行后被再次修改
- **THEN** 新文件使用保存的新增内容高亮，旧差异仍对应原执行，当前磁盘内容不影响高亮结果。

#### Scenario: 历史缺失、脱敏和预算
- **WHEN** 某侧历史证据缺失、损坏、脱敏、超预算或不能与差异行对应
- **THEN** 受影响代码安全回退纯文本，保留可用 diff 与证据入口，不泄露被移除内容；patch 不可用时保留原有不可用提示。

#### Scenario: 原文与长行
- **WHEN** 差异包含 CRLF、BOM、Unicode、无末尾换行或截断长行
- **THEN** token 对应实际展示文本，截断提示与复制行为保持原有契约，不改写源 artifact 或丢失原文入口。
