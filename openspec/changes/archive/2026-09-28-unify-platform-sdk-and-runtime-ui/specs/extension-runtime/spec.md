## MODIFIED Requirements

### Requirement: SDK 版本和命名
系统 SHALL 提供统一的公开 SDK 类型与能力目录，覆盖工具、命令、运行及工具前后钩子、清理、Provider、工作流、状态、面板及运行时 UI；默认开发入口 MUST NOT 要求按 V1/V2 选择不同接口。系统 SHALL 保留已支持旧清单和公开类型的兼容适配，独立管理协议版本；校验扩展所需能力，拒绝不兼容版本、重复注册和内置名称覆盖，诊断 SHALL 定位到来源。

#### Scenario: 请求未来能力
- **WHEN** 扩展声明当前宿主不提供的能力或不兼容协议
- **THEN** 系统拒绝激活并列出不支持项，不注册半套工具或伪装成功。

#### Scenario: 新旧扩展共存
- **WHEN** 旧版命令扩展与使用统一接口的主题及面板扩展共同安装
- **THEN** 两者在各自授权范围内工作，旧类型引用仍可校验，旧扩展不自动获得新增 UI 权限，历史事件无需重写。

#### Scenario: 查询真实能力
- **WHEN** 开发者或 Agent 查询安装版本的 SDK
- **THEN** 默认公开类型、版本信息和能力目录一致，能区分宿主支持、资源所需和实际获准能力，未授权能力不被报告为可执行。
