## Context

动机见 proposal.md。当前 `src/customization/types.ts` 导出 SDK_VERSION=1，`contracts.ts` 的 sdk=2，完整 API 使用带 2 后缀类型；文档首页与 v2.md 仍标记实施中。`PanelDefinition` 仅支持 sidebar/result 和四种面板颜色，桥接仅支持 workflow.state/answer/cancel。

`src/projection/session.ts` 将 extension.ui 的无文本负载序列化到 status 行；Timeline 同时显示组件、fallback 和 row.text。CustomPanel 无条件展示 fallback、关闭后不能重开，workbench 样式固定 iframe 高度。现有面板测试覆盖隔离、授权、构建和部分浏览器流程，但独立预览不能证明实际命令展示。用户提供的会话证实已创建并独立预览面板；截图未显示 iframe 的具体原因仍需通过真实宿主回归定位，不能仅凭导出断言挂载失败。

## Goals / Non-Goals

**Goals:**
- 用稳定契约将全局风格、扩展区域和宿主交互接入现有资源/版本/授权机制。
- 保持 Journal 为执行事实权威；UI 摘要和视觉样式不改写模型或工具原始证据。
- 让默认体验显示效果和结果，开发者仍可显式查看全部已保留诊断。

**Non-Goals:**
- 不向插件暴露宿主 React 对象、DOM、凭证或任意 CSS 注入；不承诺 Node 扩展具有 OS 沙箱。
- 不更换现有模型、MCP 或工作流引擎，不增加发布流程或自动授权。

## Decisions

### 1. 以声明式风格覆盖全局，隔离组件覆盖内容区域

新增主题和视图注册契约，沿用能力包资源和独立能力授权；主题描述按 typography、colors、spacing、radii、shadows、bubbles、assets、motion、density 分组。宿主将经过类型、范围、资源检查的值映射到稳定语义变量和有限样式预设。动效采用命名预设及有界时长/强度，不接收任意 CSS/keyframes。必要控件保留最低可读、焦点和尺寸约束。

静态字体/图像由资源内容摘要锁定，使用受控资源路径和 MIME 白名单，阻止目录穿越、外部 URL 与可执行素材；字体生成宿主受控 @font-face，失败回退到系统字体。可执行面板仍在隔离 iframe，宿主只下发主题值和允许的素材引用，不给同源身份；调整资源响应/CSP 时保留禁止直接网络和顶层导航的边界。主题和素材不成为模型上下文指令。

不选全局 CSS 注入：它无法稳定约束选择器、保护必要控件和处理多个插件。也不只扩大四个颜色 token：那仍无法完成字体、气泡与动效的整体转换。

### 2. 确定主题与区域的组合规则

用户级默认主题加工作区覆盖，工作区优先，每次只应用一个全局主题；面板局部覆盖只影响自身。主题选择保存资源 ID/revision，安装不会自动选择；预览为临时状态，取消不写入。资源更新只有在校验和既有授权满足后可切换新 revision，新能力仍需授权，失败保留旧活动版本。

普通挂件按声明 order、resourceId、viewId 稳定排序；同一消息或工具结果的 renderer 为独占选择，无选择时保留宿主默认。独立页面通过宿主导航进入，提供宿主返回入口。工具栏承载有界按钮/菜单入口，复杂交互进入视图，避免 iframe 挤占输入框。

扩展点覆盖 session header、message content、tool result、composer toolbar、sidebar widget、page。现有 sidebar/result 映射至兼容位置，不重新解释历史贡献为全局导航。宿主保留会话列表和输入框本体。

### 3. 桥接复用已有宿主命令与订阅

扩展现有实例身份、nonce、MessageChannel、序列、速率和大小限制。新增操作涵盖 draft、command、navigation、view、state；读状态与执行命令分权限，状态只返回获准的有界投影，不开放任意 Journal/凭证访问。命令走现有 commandId 去重、RecordedCall、Journal 和取消路径；工作流操作继续保留 CAS 与未知结果限制。

草稿操作默认不覆盖非空内容，冲突交给宿主确认，不自动发送。导航和视图切换不触发任务。订阅在实例关闭、版本切换、授权撤销时解除；消息不匹配当前会话或作用域时拒绝。纯视觉/导航不制造模型调用，产生运行效果的动作必须有可追溯收据。

### 4. SDK 统一命名，内部协议独立演进

将完整公共接口作为 ExtensionAPI/ExtensionFactory 默认含义，旧带后缀接口保留为兼容别名，旧清单经 adapter 校验；默认 SDK_VERSION 与能力查询对应当前契约。manifest、rpc、ui 等协议保留独立数字与显式兼容范围，不把所有数字机械改成同一值。新增能力不能通过旧清单/别名绕过授权。

统一公共目录包含契约说明与可解析类型，避免 Agent 只能看到一个 re-export 文件。脚手架、候选校验、试验、包安装和文档共用能力定义；浏览器面板类型保持可安全类型导入，不要求打包 Node 运行时代码。

文档入口改为任务导航，覆盖全部能力及组合路径；每篇包含权限、最小完整示例、错误/取消/恢复与验证。旧文档路径保留指向新入口的兼容说明，历史 archive 和验证记录不伪装成当前指南。样例同时提供完整主题包、命令结果面板及宿主工具栏操作，素材附许可；安装 tarball 离线验证类型和文档可达。

### 5. 用户展示与证据分离，面板状态显式化

贡献增加可读 summary/displayName 的兼容字段，props 与原始事件/artifact 不变。投影为 UI 贡献保留明确展示类型，禁止将整个 envelope 作为普通 status 文字。对旧记录按有界通用字段展示值，不识别特定插件名字、不调用模型生成摘要；缺失内容诚实提示。HTML 导出共享语义展示，不加载插件脚本，技术字段进入折叠证据。

当前事件流以本次连接的初始历史水位/事件身份区分新结果和重放，不能仅根据 completed 判断自动挂载。新结果经当前授权/版本检查后挂载；刷新、恢复、导入只展示静态内容。历史显式打开不重跑命令。

状态机为 loading/ready/failed/collapsed，fallback 仅用于非 ready 状态。重试创建新实例，收起解除通信且可重新打开。props 和面板身份保持稳定，普通父组件渲染不重新挂载；主题更新通过受控消息下发，保持组件输入。通过受限 resize 消息自适应高度，宿主设置上限/频率并提供滚动，不接受任意布局样式。

### 6. 权威状态与故障恢复

运行、工具、工作流事实继续由各自 Journal 管理，渲染只读投影。主题选择是宿主配置，授权由既有资源授权记录管理；浏览器缓存不是授权或任务状态权威。配置变更使用修订冲突检查并记录来源，跨窗口刷新投影。启动时验证所选资源，失效即回退默认，保留诊断和历史选择。

恢复默认入口在宿主控制区可通过键盘访问，禁用扩展视觉和视图后仍可查看会话、停止任务及管理资源。取消预览/候选开发保留原活动版本。恢复界面不回滚运行历史或重做外部动作。

## Risks / Trade-offs

- [主题维度广，容易只覆盖部分页面] → 建立导航、会话、输入区、普通控件、面板的 token 覆盖矩阵，使用完整主题做浏览器验收。
- [主题字体缺字/加载失败，背景降低对比] → 系统字体回退、装饰层和内容层分离，验证中文、代码、焦点、200% 缩放及减少动态效果。
- [新资源路径或桥接扩大权限面] → 校验路径/MIME/摘要/授权，负向测试伪造身份、撤权、外部资源和重复命令；保持 iframe 隔离。
- [SDK 同名类型升级产生隐式兼容问题] → 保留旧入口，使用历史清单与旧源码 fixture，在实际 tarball 中做新旧编译和运行回归。
- [历史数据没有有意义的摘要] → 使用有限通用渲染并保留原证据，不宣称能完整重建旧插件视觉。
- [截图 iframe 缺失尚未定因] → 实施时在真实宿主重放等价夹具，记录加载、握手、关闭状态；未复现的部分明确记录，不能靠样式修复宣称根因消失。
- [现有测试偏重隔离而非观感] → 加入实际命令链、主题覆盖、无技术字段泄漏、恢复操作与不同视口的集成断言及截图审阅。

## Migration Plan

1. 先增加 UI 契约、资源与权限适配，再接入主题、扩展区域和桥接，旧包保持原行为。
2. 在新增能力稳定后统一 SDK 目录、脚手架与文档，保留旧版本适配和说明。
3. 修正展示投影、面板状态与离线导出；对旧历史采用读取时投影，不批量改写 Journal。
4. 完成类型、单元/集成、浏览器和安装包验证后再考虑归档；本 change 不包含 push、标签或发布。
5. 失败时先关闭新主题/视图恢复宿主默认，再回退兼容代码或包活动指针；保留配置与事件，不能自动回退不兼容状态或重跑未知工具。
