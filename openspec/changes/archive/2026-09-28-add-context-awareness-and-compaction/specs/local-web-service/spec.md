## ADDED Requirements

### Requirement: Web 启动自动打开浏览器
`nekomimi web` SHALL 在服务成功监听后自动请求系统默认浏览器打开实际连接 URL，支持指定工作区和随机端口，保留当前连接授权；`--no-open` SHALL 禁止自动打开。程序化启动服务、其他子命令和无参数帮助 SHALL NOT 隐式打开浏览器。浏览器不可用或打开失败 SHALL 保持服务可用并输出可手动访问的地址，失败消息不得额外暴露连接凭据。

#### Scenario: 本地正常启动
- **WHEN** 用户执行 nekomimi web 且服务获得监听端口
- **THEN** 默认浏览器收到包含必要连接信息的实际 URL，每次启动只请求一次；不使用猜测端口，也不在启动失败时打开页面。

#### Scenario: 无浏览器环境与关闭自动打开
- **WHEN** 用户传入 --no-open，或运行环境无法打开系统浏览器
- **THEN** 前者不启动打开进程，后者给出简短提示；两者均保留终端地址、运行服务和正常退出能力。
