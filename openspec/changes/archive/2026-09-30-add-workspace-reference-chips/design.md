## Context

动机与范围见 `proposal.md`。本变更跨输入编辑、工作区查询及工具提示词，因此需要设计统一语义。

当前代码事实：

- `Composer.tsx` 使用 textarea，拥有命令候选、组合输入、草稿、提交及焦点逻辑；选择范围依赖字符串偏移，不能直接呈现行内引用块。
- `command-input.ts` 只识别输入开头的命令词；正文引用需根据实际光标位置识别，不能沿用首词正则。
- `server/workspace.ts` 提供目录分页、逻辑路径和 realpath 校验，`server/app.ts` 已有认证后的 `/workspace/files` 接口，但没有跨目录模糊检索。
- `Submit` 只有文本 prompt；服务端按 prompt 计算去重哈希。`tools.ts` 的 read 已提供有界文件读取与记录，目录可通过当前可用 shell 工具检查；引用无需增加另一套文件内容注入链路。
- 参考本机 `@deepseek-ai/dsh` 0.1.7-rc.2 中 `dsh-client-ui-reference`、`dsh-file-reference`、`dsh-file-reference-local` 的已安装构建代码：路径候选、目录 drill、引用块和 path-only guidance 已核对。上游仓库为 https://github.com/deepseek-ai/deepseek-harness 。未做该版本真实 UI 验收，不把源码观察写成性能或浏览器实测结论。

## Goals / Non-Goals

**Goals:** 用一个可序列化的编辑模型保存正文与引用；目录发现只提供候选，实际读取保持原证据链；新编辑器满足已有草稿／命令／焦点契约。

**Non-Goals:** 富文本格式工具栏、自动附件、拖拽上传、跨会话引用、工作区外引用、编辑器状态持久化协议或历史消息引用块迁移。发送后的时间线仍按既有文本消息展示路径。

## Decisions

### 1. 限定的行内编辑模型

使用 text 与 reference 两种片段：text 保存正文和换行，reference 保存逻辑相对路径及 file/directory 类型。引用块是原子节点，标签从路径派生；不把 DOM、展示标签或文件内容作为权威输入。选区保存片段位置与偏移，DOM 选区只做映射。

将编辑适配抽为独立组件，使用受限 contenteditable 和不可编辑引用节点，暴露 getSerializedText、focus、selection 与替换范围能力。React 管理外围 UI；组合输入期间不重建编辑 DOM，不插入候选或移动选区。通过 beforeinput/input/composition/selectionchange 归一化编辑事务，提供统一的有界撤销重做历史，覆盖普通输入、组合提交、引用插入、粘贴和删除，避免原生撤销栈与程序改 DOM 相互冲突。首版不引入通用富文本框架；这一选择必须以真实浏览器编辑用例验证，不能仅凭 DOM 快照证明可用。

替代方案：textarea 上叠加装饰层难以保证块选择、移动端光标与复制一致；仅补全文本不满足已确认的引用块需求；通用富文本框架为两个节点类型引入较大能力面，暂不采用。

### 2. 单一候选控制器与明确目录动作

命令与引用候选共用弹层布局和可访问选中状态，同时仅一类候选打开。引用触发位于正文起始或空白边界；邮件、已有块以及 Markdown 行内／围栏代码区域不触发。选区非折叠时先按普通编辑处理；只有折叠光标所在文本片段可触发。

Enter／Tab 引用当前条目；目录右侧“进入目录”按钮与 ArrowRight 下钻，面包屑可点击，空目录查询下 ArrowLeft 返回父级，Esc 关闭。每种动作显示短提示，不让用户猜测 Enter 是引用还是进入。引用后插入一个可编辑分隔空格并落位到块后；不替换后续正文。外部点击或 Esc 的关闭状态在查询词实际改变前保持。

请求绑定工作区、会话上下文、查询词、导航目录与递增代次。取消前一请求并在返回时核对代次；会话切换／卸载清理请求和候选。引用匹配复用与命令补全互斥的键盘路由，保留 IME 与重复 Enter 保护。

### 3. 路径语法与剪贴板保真

纯文本序列化采用 `@src/main.ts`、`@src/`；含空白、双引号、反斜杠或其他易混淆分隔符时采用 `@` 加 JSON 风格双引号字符串，目录斜杠在引号内，例如 `@"my docs/"`。引号和反斜杠分别转义为 `\"` 与 `\\`；控制字符路径明确不可引用。前后端共享规范化／编解码函数；保留大小写、Unicode 和逻辑别名，不将规范化物理路径替代用户看到的路径。

复制和剪切始终提供 text/plain 的规范文本；应用内另带版本化片段 MIME 以恢复引用块，元数据只作为不可信输入，经过 schema、大小及工作区路径校验后才恢复。跨应用粘贴缺少片段 MIME 时作为普通文本保留，不自动将所有 `@` 文本转成引用块，也不接受富文本 HTML。校验失败退回纯文本并提示，不能丢失粘贴内容。普通文本路径仍可被模型按引用语法理解。

这一转义是 nekomimi 的明确语法扩展，不宣称与 dsh 的全部特殊文件名行为相同。

### 4. 独立、有界的只读候选接口

新增 `GET /api/v1/workspace/references`，参数包括 query、可选目录游标与 refresh；不改变 `/workspace/files` 的既有分页。响应含 path、name、kind、候选 revision、可选 next、limited；失败返回明确错误，取消传播到枚举器。该接口另提供 `mode=resolve&path=...` 的精确路径校验模式，用于选择及内部剪贴板引用恢复；仅返回规范逻辑路径和类型，不读取正文，校验与搜索共用边界。

无查询词时展示根目录；不含路径分隔符时做全局模糊查询；有路径前缀或下钻状态时使用实时目录分页。全局排名依次为名称精确、前缀、包含、路径包含、子序列，最终以目录类型与路径打破平局。默认每次 20 项、索引最多 50,000 项；达到索引上限返回 limited，不把它当成完整项目搜索。定向目录使用分页继续，不受全局索引截断阻断。

全局索引仅缓存路径和类型，默认跳过 `.git`、`node_modules`、`dist`、`build`、`.next`；默认不列隐藏条目，明确点号查询／目录路径可访问隐藏项和默认排除目录。首版不承诺完整 gitignore 规则解释。索引按工作区复用、合并并发扫描，采用短时有效期（初值 5 秒）和显式刷新；扫描中的取消及时停止无人使用的遍历。候选展示时和引用校验时重新检查选中路径，防止陈旧索引提供有效假象。

复用 `workspacePath` 的工作区与符号链接边界。全局递归不跟随目录符号链接，目录条目可作为逻辑别名展示并经显式下钻校验；祖先循环不可进入。接口不读取文件正文、不执行 shell 建索引、不调用模型。

### 5. 保持提交和证据链一致

发送时从编辑模型生成一个确定的 prompt 字符串，沿用当前 `Submit`、commandId、payloadHash 和任务运行接口；32,000 字符限制按序列化文本计算，不按引用块短标签计算，纯引用输入也可发送。失败保留模型和选区，成功只清理对应草稿版本；等待期间的新编辑及会话切换必须隔离，避免将引用块作为单独附件状态后漏清理或误清理。

通过启用工具的 guidance 说明：相对引用以工作区为根；引用不等于已读取；文件需要 read，目录使用当前可用的目录／shell 能力，正确引用文件名，不自动递归读取。工具不可用时报告限制。引用自身不授予读取之外的修改或执行权限。

Journal 保留用户发送的规范路径文本，工具调用和结果记录实际读取版本；文件被修改、删除或链接重定向后，以工具执行时校验为准。重放、导入、导出不重新解析路径并读取当前文件。不要将候选选择时的文件元信息冒充读取快照。

## Risks / Trade-offs

- [contenteditable 的 IME、选区和撤销复杂] → 独立编辑模型与适配，真实浏览器验证组合输入、跨块删除、剪贴板及撤销；沿用命令和焦点回归，未验证设备明确记录。
- [路径缓存陈旧或大仓库扫描慢] → 有界索引、取消、刷新、受限提示和定向目录分页；记录固定 fixture 的查询与输入响应，不用结果上限掩盖遗漏。
- [长路径和多个引用挤压窄屏] → 引用块限宽折行／省略、完整可访问名称、可达删除按钮与有界候选；发送区不被遮挡。
- [选择后文件变化] → 引用按路径语义，实际读取再次校验并留证；不承诺内容快照。
- [富剪贴板跨工作区与注入] → 将元数据视为不可信数据，重新校验并可回退纯文本；禁止粘贴 HTML 进入编辑器。

## Migration Plan

先建立语法和模型测试，再接入候选接口、编辑器和工具 guidance，最后运行完整交互与证据回归。没有数据迁移，旧客户端／历史记录兼容；回滚 UI 和候选接口不影响已提交的路径文本。落地后记录真实浏览器覆盖范围与性能采样，完成 tasks 后才可归档；本提案不包含提交、发版或发布动作。
