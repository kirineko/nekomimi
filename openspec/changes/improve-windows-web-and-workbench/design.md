## Context

src/server/app.ts 使用 realpath(file).startsWith(realpath(staticDir) + "/")；Windows 返回反斜杠路径，合法首页被拒绝。node:path.win32 模拟已复现。CoreTools 的 relative/isAbsolute 边界逻辑可参考。App.tsx 使用 split("/") 取工作区名，也存在 Windows 展示问题。

styles.css 将会话及输入区限制到 760px；Timeline 将调用、回答、完成和命名单独渲染。useSession 保留最多 180 行但每次更新重建 rows，优化应基于测量，不能破坏分页或流式跟随。

## Goals / Non-Goals

**Goals:** 修复 Windows Web 入口，提升大屏信息密度与阅读层级，保留品牌与证据可追溯性。

**Non-Goals:** 不重命名产品、不新增主题切换、不迁移 UI 框架、不升级依赖、不修改导出格式。原生 Windows 验证范围外的功能不宣称全面支持。

## Decisions

### 跨平台资源边界

提取可测试的资源路径判断，先 realpath，再 relative(root, target)，拒绝父目录、跨盘绝对路径及根目录本身；按平台路径语义判断，不简单替换字符或取消校验。保留路由白名单、Host、Origin 和凭证策略。覆盖 Windows 盘符、空格/中文目录、兄弟目录前缀碰撞、符号链接越界与 POSIX 回归。工作区显示名称同时处理两种分隔符，不改变工作区身份计算。

### Windows 实机验收

安装脚本按平台解析 npm 全局命令 shim，处理 npm.cmd 调用；合成工具调用使用平台真实工具名称及 shell 命令，不能固定 bash/pwd。增加 windows-latest 原生验收工作，保持仅版本标签触发；正式发版前仍等待所有标签检查完成。本地路径模拟不能替代该检查。实现阶段可用已有 Windows 环境验证；不可用时保留未完成项，安排下一次授权标签 CI 验证，禁止擅自发版凑验收。

### 视觉系统与组件结构

采用 frontend-app-builder 的先设计后实现方式：实现阶段生成完整会话及追踪状态设计稿，确认后提取 token 与组件规范；探索截图是问题证据，不是像素级目标。设计稿和运行截图置于临时目录，不提交仓库。

建议初始尺寸：侧栏 220–248px、顶栏 48–56px、正文 14–15px、辅助文字 12–13px，间距按 4/8px 级别统一。工具和代码区域随工作区扩展，正文独立限制阅读行长；不把整页固定到 760px，也不把正文无限拉宽。短用户消息按内容适度收缩。输入框默认紧凑且可增长，保留 Enter/Shift+Enter/IME 保护。宽屏追踪并排，空间不足改抽屉，避免主区域被挤压。

### 对话与证据分离

基于已有运行/调用标识建立纯展示投影，不按文本猜测分组、不改写 Journal。每轮保留任务、工具进度和回答，重复成功状态合并；会话命名等后台调用放到可访问的追踪入口。失败、取消、结果未知保持显式提示。分页截断的轮次允许部分展示，不能丢失证据入口。

### React 检查

使用 react-best-practices 对实际改动检查：将消息行、轮次摘要及布局拆分，测量长会话流式更新后决定 memo/延迟渲染；昂贵详情按需加载。保持稳定 key、Effect 清理、切换会话的过期请求防护。Vite 项目使用 React 支持的加载方式，不引入 Next.js 专用 API。

## Risks / Trade-offs

- 紧凑布局影响阅读 → 正文行长独立控制，检查 1440×900、1920×1080、1280×720 和 390×844。
- 隐藏状态损害可观测性 → 完整调用在追踪中可达，错误与未知状态默认可见。
- 路径修复放松安全边界 → 合法资源与越界拒绝配对测试，真实路径校验保留。
- Windows 环境与权限差异 → 原生安装验收单独记录，symlink 权限不足时明确标记，不能将跳过记为通过。
- UI 重构影响持续输出 → 覆盖滚动跟随/手动上滚/分页/切会话/IME/取消/删除/导出回归。

## Migration Plan

不迁移持久化数据，不改变 API 或 Journal schema；随未来正常版本交付。只在原生验收通过后更新 Windows 支持声明；回滚实现无需回滚会话数据。

## 已确认视觉规范

用户已确认完整会话、追踪并排和移动端概念。采用 232px 侧栏、54px 顶栏、400px 桌面追踪栏、正文 15px/1.65、辅助文字 12–13px；宽屏工作区最大 1120px，正文独立限制 78ch。使用中文文案和原有 Brand；不实现概念图中的模型切换、附件入口或虚构统计。样式扩展位于 src/web/styles/workbench.css；轮次投影与焦点行为独立模块化。
