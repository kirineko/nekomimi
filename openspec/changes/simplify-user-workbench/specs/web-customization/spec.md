## MODIFIED Requirements

### Requirement: 分类导航与渐进展开
系统 SHALL 以创造工作台和能力目录替代以管理弹窗为中心的布局。创造导航 SHALL 默认只显示“新建开发目标”、开发目标会话列表和当前目标的候选；可用与待处理能力以计数摘要显示，点击后进入能力与权限页面。候选、能力包、权限、MCP、工作流及诊断 SHALL 通过设置菜单与 `/create/settings` 设置总览中的文字入口到达；模型配置有独立入口。原始能力阶段码、目标宿主 build 与资源 revision 属于开发者视图或资源详情的“技术详情”。高级原始数据按需展开，页面导航和返回入口在滚动时可达，未选视图不堆叠；工作视图保留能力使用和进入创造的入口，但不伪装成已切换模式。

#### Scenario: 初次打开面板
- **WHEN** 用户打开创造工作台
- **THEN** 看到开发目标创建表单、目标列表、可用能力计数和明确空状态；不默认展示 JSON、原始能力清单、阶段码或全部开发文档。

#### Scenario: 切换分类查看资源
- **WHEN** 用户打开资源详情
- **THEN** 来源、版本、范围、遮蔽、诊断、启停、授权、验证和重载可到达；导航本身不执行这些操作。

#### Scenario: 设置总览可达全部管理页
- **WHEN** 用户打开 `/create/settings`
- **THEN** 以分组卡片列出模型、能力与权限、MCP、能力包、面板、工作流、主题与基础设置，每项都有文字链接和一句用途说明。
