## ADDED Requirements

### Requirement: 证据入口默认收起且可达
调用证据检查器 SHALL 在开发者视图关闭时，通过会话操作菜单“调用证据”、对话中每轮的“查看证据”链接以及详情抽屉中的证据标签到达；这些入口打开同一检查器、同一证据。检查器内部展示 MUST NOT 因开发者视图开关而增删 attempt、请求 body、hash 或原始响应；开关只控制检查器外部（时间线、头部、侧栏）是否内联展示运行 ID 与 hash。读取证据 MUST NOT 执行脚本、扩展工厂或模型调用。

#### Scenario: 从对话轮次查看证据
- **WHEN** 开发者视图关闭，用户点击某轮回复旁的“查看证据”
- **THEN** 检查器打开并定位到该轮运行，显示逐 attempt 的请求 body/hash 和原始响应。

#### Scenario: 开关前后证据一致
- **WHEN** 用户分别在开发者视图开启与关闭时打开同一运行的检查器
- **THEN** 两次可见的 attempt 数量、请求 hash 和原始响应内容完全一致。
