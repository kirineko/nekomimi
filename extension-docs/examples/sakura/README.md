# 樱花手记组合示例

复制整个目录到工作区 `.nekomimi/extensions/sakura-studio/`，或用 `nekomimi packages prepare` 的本地源准备能力包。通过完整类型校验后，在定制能力中信任并启用，再在「外观」预览并选择「樱花手记」。执行 `/moe 小猫咪`，面板应直接显示，便签按钮只写草稿，不自动发送。主题覆盖字体、排版、配色、间距、气泡、素材及动效；输入框旁提供灵感入口。

权限见两个清单；不调用真实模型或网络。Node 工厂只注册定义，浏览器组件返回清理函数。停止任务走宿主入口；收起面板解除实例，禁用包或恢复默认不修改会话证据。验证：类型检查 → 独立预览 → 实际宿主命令与写草稿 → 刷新静态摘要 → 重新打开 → 禁用/离线导出。独立预览不代表宿主验收完成。

`sakura.png` 为项目生成的装饰纹理，沿用仓库 MIT 许可。`demo.woff` 从 Bitstream Vera Sans 转换并重命名为 Nekomimi Demo，许可和原版权见 FONT-LICENSE.txt；仅含部分拉丁字符，中文由系统 sans-serif 回退。它演示离线字体加载，不承诺覆盖全部语言。不要把演示字体许可误认为所有第三方素材的许可。
