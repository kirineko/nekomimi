# 上下文占用与整理

会话标题旁的“上下文”按钮显示**当前主模型下一次请求**的上下文估算，点击可查看系统提示词、工具定义、对话消息三类明细。它不是累计用量或账单。数字带 `~`：中文、英文、工具 JSON 和图片采用确定性估算；图片缺少模型计量规则时使用保守近似，不按 base64 字符串长度计算。整理早期图片时摘要输入使用明确的附件占位说明，不把图片编码伪装成正文；图片原件仍保留在历史中。匹配的服务端 input usage 可用于校准；换模型、工具、提示、Provider 协议或压缩检查点后，旧样本失效。模型容量未知时不显示百分比，也不自动压缩。

## 自动整理

默认开启，可在设置的“自动整理上下文”或 `nekomimi config` 中关闭。旧配置自动按开启处理，保存后跨重启保留。关闭不会撤销已完成的摘要。程序化 `run({ …, autoCompact: false })` 可单次关闭。

每次主模型请求前检查占用，包括工具循环后的请求。设模型窗口为 W、输出预留为 O、安全余量为 `max(1024, ceil(W × 2%))`，策略版本 2 另为带工具请求保留可能结果 R：`min(2048, floor(W × 2%))`，无工具时为 0；输入预算 B 为 `W − O − 安全余量 − R`，触发点为 `min(W × 80%, B)`。保留近期内容目标为 `min(W × 16%, B × 50%)`，始终保留最新任务及完整工具调用/结果组合；不会强行拆分它们。输出预留超过窗口或近期完整交互过大时停止并提示处理，不无限重试。

`128K` 输出、`64` 轮是现有默认上限；整理不扩大它们。自定义模型的实际输出上限仍受声明的 `maxOutputTokens` 限制。

## 手动整理

在 Web 输入框发送 `/compact`，或添加保留重点：

```text
/compact 保留未完成任务、修改过的文件和用户限制
```

CLI 可以使用 `nekomimi resume <session-directory> '/compact 保留文件路径'`。命令纳入补全并保留给宿主，扩展不得覆盖。无早期可整理内容时不会请求模型；任务繁忙时拒绝并发操作。Web 重发同一 commandId 不会重复执行。

整理使用当前主模型，输入中没有可执行工具，输出最多 8192 tokens（同时受模型和显式输出限制约束）。摘要调用单独标注 `compaction`，可在调用证据中检查请求、响应和用量；可能分多次生成摘要，会产生额外费用，且摘要可能丢失细节。可点击停止取消。网络错误、不完整响应、空摘要、没有缩减、上下文变化或取消时都不会应用检查点。

## 历史与 SDK 边界

Journal 仍保留全部聊天、工具结果、附件及摘要证据，历史查看和导出不会缩短。只有后续模型请求使用“摘要 + 近期完整内容”。回放、刷新、导入不会重新执行工具或调用摘要模型。不要将读取到的历史面板或 `compaction.completed` 当作实时执行请求。

`Snapshot` / SSE `Update` 具有可选 `context` 和 `compacting` 字段，旧记录没有这些字段也可正常查看。`ContextOccupancy` 包含 revision、model、provider、contextWindow（未知可省略）、三类 tokens、totalTokens、method（estimated/calibrated）、imageEstimate 和校准 anchor。读取接口只返回统计，不激活资源或模型；统计不随可见历史分页而变化。包根入口导出 `ContextOccupancy` 类型。

Provider 的 `contextWindow`、`maxOutputTokens` 和协议声明必须准确。宿主将有效上下文传给 `serialize`，适配器不应自行追加旧历史或重新注入摘要。当前可验证的压缩协议为 `responses` / `chat-completions` 的标准化节点。其它协议保留正常运行能力，但无法安全整理时明确拒绝；不猜测私有协议关联。自定义序列化的额外开销仍属于估算不确定性。

检查点以版本化事件记录摘要 artifact、被替换的节点引用/哈希、上次检查点和源 revision，在 Journal 写入队列内比较后一次提交。只有完成事件改变上下文投影；开始、失败、取消事件不改变投影。原始未知工具结果恢复始终读取原始历史。

摘要来源同时固定会话、模式、完整目标、模型配置和有效声明版本。在每段生成后、附件保存后及最终写入队列内重新检查来源和当前授权；模型资料、目标、能力或必须保留的状态变化后，旧摘要不提交。最终同步门禁再次检查取消和源身份，覆盖异步检查完成到实际提交前的微任务取消。授权拒绝属于摘要失败，保留失败事件和原投影，不将它伪装为 Journal 写入损坏。同一会话不能递归或并发压缩；Durable 内置压缩保持关闭。

创造整理单独保留提交时的目标宿主、候选／活动版本、各实际验证阶段及证据引用、待授权和待应用状态。UNKNOWN 工具与未结束交互由 Journal 保留，已确认交接的约束仍是数据。模型返回的摘要不能覆盖这些事实，也不能由预览成功推出已经应用。保留数据以 64 KiB 为安全界限，无法装入模型输入预算时保留原上下文并拒绝整理，不静默删掉未完成状态。生命周期历史原件保持不变，摘要只携带当前候选／活动版本各阶段的最新记录；这份提交时快照不是永久的当前状态，后续可靠事实优先。查看这些状态不运行资源工厂，主题默认值读取也不创建目录。


当前统计另有 mode、targetId、purpose、capabilityRevision、policyVersion、reservations、layers 和 exclusions。分层 tokens 的合计与三类总量一致；层的 estimatedTokens 与校准 adjustmentTokens 分开，仍是估算，不宣称 Provider 实测了每层费用。usage 锚点绑定模式／目标、声明、提示词、模型和编码；图片改变后旧样本失效。辅助命名、压缩、交接及 SDK 模型 usage 不计入主占用。容量未知时不产生输入额度、安全／结果预留或百分比，输出预留仍按明确配置显示。

大工具结果先保留经过凭证保护的完整 JSON 附件，再按版本 2 策略投影。文本按 UTF-8 及 JSON 编码预算截取，明确给出省略字节数和完整附件续读入口；图片单独选择，不把 base64 当文本截断。最多保留 4 个图片，受 4 MiB 证据界限约束；省略图片可用 `read({path:"artifact:<完整工具结果 hash>",imageIndex:<原 content 索引>})` 读取，不运行原工具。原文件翻页 nextOffset 若对应完整返回，裁剪后放在 sourceDetails 中；投影本身的 resume 指向完整结果附件，不能将原 nextOffset 当作已读完可见文本。tool.projection 保存原附件、投影附件、保留项和宿主续读 framing，请求选择条目引用同一转换证据。

### 确认交接的上下文

确认收据只保存快照，不启动任务。创造任务开始时选入已确认的工作输入；工作任务需要显式选择交付 ID，之后作为历史数据保留。引用按确认顺序记录原 payload hash、脱敏后的 data hash、来源范围和本次 include/exclude 理由，完整确认快照仍可按附件读取。

交接正文使用 user 数据帧，原角色、工具调用和 UNKNOWN 只是引用事实，不能变成宿主指令或可执行调用。工作请求排除开发指南正文；目标、工具声明及授权仍独立校验。摘要最多 16000 UTF-8 字节，每条引用文本最多 4000 字节，最多保留 4 张内联图片；省略量和完整快照入口可查。

来源只读检查失败时，已确认副本保留，后续请求与来源索引标注原证据不可用。不会重新读取来源正文覆盖副本。已保存投影必须与确认快照一致，恢复不重新授予权限或应用候选。

### Codemode 脚本与状态

有效工具中提供 `codemode({code})`，代码是异步 JavaScript 函数体。`ALL_TOOLS` 列出本脚本可发现的工具及输入 schema，`tools.<name>(args)` 调用同一宿主管线；发现不授予权限，工作模式不开放创造工具，不能递归启动 codemode。`text()` 和 `image()` 收集结果，`return` 返回值；没有 process、网络、文件系统或模块加载入口。空 code 返回当前固定资源限额。

默认总时限 30 秒、内存 16 MiB、源码 256 KiB；输出最多 16 Mi 字符和 100,000 项。每脚本最多 128 个子调用，同一运行中同时执行最多 4 个，同资源最多 2 个。完整子调用证据独立保留，模型只接收有界投影和完整附件入口。MCP 的 isError 可作为结构化结果处理，子调用仍记为失败。脚本抛错不撤销已完成写入。

`load(key)` 读取当前会话的小状态，`store(key,value)` 暂存变更，undefined 删除键。只有成功且未在提交前取消的脚本提交状态；单值最多 256 Ki 字符、总状态 1 Mi 字符，并发旧版本提交会失败。重开读取 Journal 的成功状态，历史分支复制对应快照，后续修改互不影响。失败脚本的 storeWrites 不进入状态；这与已发生的工具副作用不是同一个事务。

脚本结束会请求取消未等待调用，并给出有界收敛时间。无法确认的已派发结果保持 unknown，不能把取消当成回滚或自动重试。完整脚本结果为持久 JSON 附件，图片另存字节附件；大输出和图片省略时保留读取入口。
